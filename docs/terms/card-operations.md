# 与操作游戏牌相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。MoveCardEvent/UseCardEvent/DropCardEvent 及各卡牌操作快捷方法的规则依据。

---

## 通用缩减规则（多处引用）

对于"\<操作> X 张\<牌>"或"\<操作>所有\<……牌>"类操作，**若并非**是作为：

- 发动一个技能的**消耗**或**唯一效果**，或
- "**▷**"左边最近的一个效果，或
- 选项中**唯一能执行的无条件执行**的效果，或
- **须选择是否执行**的效果

则执行此操作即 \<操作> **min{能\<操作>的\<牌>数, X}** 张（"所有"版本即操作所有能操作的牌）。

> 适用于：置入（装备区/判定区）、弃置、获得（见各条目）。反之（在例外清单内）则必须足量执行，否则不能执行。

## 移动类操作

### 移至 \<一个区域>

将一张牌**从另一个区域**移动到此区域。此牌移动前必须**不在**该区域内（例：司马懿不能〖反馈〗自己的手牌）。

### 置于/入

将牌移至目标区域并按**该区域的默认放置方式**放置。

◆ **装备牌非因使用置入的限制**：不能将武器/防具/坐骑/宝物牌**并非因使用**而置入一名对应装备子区**里有牌**或对应装备子区**处于封印状态**的角色的该装备子区。（例：〖巧变③〗能移防具给无防具的角色，不能移武器给已有武器的角色）

◆ "将 X 张/所有牌置入装备区或判定区"适用[通用缩减规则](#通用缩减规则多处引用)（min{目标区域不处于封印状态的牌数, X}）。

◆ **延时锦囊非因使用置入判定区**：须先通过系统对其**使用此延时锦囊牌的合法性检测**（牌面"使用目标"产生的规则不影响此检测）。执行此操作会将原目标移出目标列表，并生成新目标加入。（例：〖巧变③〗可将【兵粮寸断】移入已有【乐不思蜀】的判定区，不能移入贾诩或已有【兵粮寸断】的判定区；自己判定区没有【兵粮寸断】则可移给自己）

### 扣置于/入

将牌移至目标区域且**背面朝上**放置。

### 弃置

将一名角色**区域里**的牌移至弃牌堆。

> **"弃置"是操作，"移至弃牌堆"是结果。**

◆ **谁选牌**：A **令** B 弃置牌 = B 执行弃置（B 自己选牌）；A **弃置** B 的牌 = A 执行弃置（A 选牌）。

◆ "A 不能弃置 B 的……牌" = A 选择时不能选 B 的……牌（其他角色仍能弃置）。

◆ "A 被弃置的牌"包括 A 弃置的自己的牌**和**其他角色弃置的 A 的牌。

◆ "弃置 X 张/所有……牌"适用[通用缩减规则](#通用缩减规则多处引用)。（例：〖英魂〗令只有两张牌的陆逊弃三张 → 弃全部两张，之后〖连营〗仍能发动）

### \<角色A> 将……牌交给 \<角色B>

A 将这些牌移至 **B 的手牌区**。

注意：1、A 与 B 可以是同一名角色；2、这些牌不能是 B 拥有的牌。（两条叠加 → 角色不能将自己的手牌或装备区的牌交给自己）

◆ **分配方式**（多牌多角色）：选 X 张牌，同时选 Y 名角色（Y∈[1,X]），同时确定分配方式（每名角色**至少一张**、合计 X 张），然后**同时**交给。"交给**等量的**\<角色>" = X 张牌 X 名角色**各一张**。

◆ A 将多个区域里的各一张牌交给 B = 每个有牌的区域各选一张，**同时**移至 B 手牌区。

### 获得 \<牌> / 得到

- **获得**：一名角色将这些牌移至其手牌区的**操作**。
- **得到**：牌移至一名角色的手牌区，即其得到这些牌——**结果**。（例：〖反馈〗= 因获得而得到；〖仁德〗交给 → 对方因交给而得到 → 触发〖恩怨①〗）

◆ "获得 X 张/所有牌"适用[通用缩减规则](#通用缩减规则多处引用)。

◆ A 获得 B 的多个区域里的各一张牌 = 各选一张**同时**移至 A 手牌区。

◆ 得到牌后须将所有手牌洗混；若在使用结算中得到且后续效果须对其中至少一张操作，则洗混**除这些牌外**的手牌（同 [zones.md](zones.md) 手牌区洗混规则）。

### 失去 \<牌> / \<手牌> / \<装备区里的牌>

- 角色的牌移至**除其手牌区和装备区外**的区域 = 失去这些牌
- 手牌移至目标区域 = 失去这些手牌；装备区里的牌移至目标区域 = 失去装备区里的这些牌

> 例（连锁触发）：邓艾使用【藤甲】→ 实体牌先置入处理区（失去手牌 → 〖屯田①〗）→ 置入装备区同时【八卦阵】置入弃牌堆（失去装备区牌 → 再次〖屯田①〗）。

### 交换

**手牌区所有牌**：双方均有牌 → 同时将所有手牌**扣置入处理区** → 同时将处理区里原本为对方所拥有的牌扣置入自己手牌区；仅一方有牌 → 单向执行。

**装备区所有牌**：双方先同时置入处理区，然后按"对方牌与己方装备区是否有**同种**装备牌"分支——均冲突 → 全部置入弃牌堆；均不冲突 → 互相置入装备区；单方冲突 → 不冲突方入装备区、冲突方的入弃牌堆。

**各一张确定的牌**：同时置入处理区 → 同时扣置入自己手牌区。

> 注：处理区是公共区域，处理区的牌**不属于任何角色**——交换不会触发〖恩怨①〗（不构成"交给/得到"）。

### 重铸

将此牌置入弃牌堆，然后摸一张牌。◆ 不能同时重铸两张或两张以上的牌。

### 摸……张牌

获得**牌堆顶**的……张牌。

### 将 \<牌> 弃置至 \<X> 张 / 补至 \<X> 张

- **弃置至 X 张**：牌数 > X → 弃置（牌数-X）张；≤ X → 没有事发生
- **补至 X 张**：牌数 < X → 摸（X-牌数）张；≥ X → 没有事发生

### 洗牌

系统将**弃牌堆里的所有牌置入牌堆**，然后将牌堆里的所有牌洗混。

## 使用/打出类操作

### 使用

触发一个**预使用牌事件**，然后触发一个**使用事件**的操作。◆ 角色不能同时使用两张或两张以上的牌。

### 打出

触发一个**打出事件**的操作。◆ 角色不能同时打出两张或两张以上的牌。

### \<一名角色> 能如手牌般使用或打出 \<牌A>

若其于预使用/打出牌 B 的流程中选择牌 B 对应的实体牌的范围为**其牌或手牌**、且有**特定的数量**，则所有符合选择标准（**除区域标准外**）的牌 A 也进入选择范围。

> 注（木牛流马"辎"）：角色相当于拥有一个小牌库，但"辎"**不算手牌**——拥有部分操作权但没有所有权。〖义绝〗〖潜袭〗等封手牌的技能对"辎"无效。
> 例：〖奇策〗须以**所有手牌**（非特定数量）使用【无中生有】→ 不能混入"辎"；没有手牌也不能只用"辎"发动。

### 拼点 / 判定

触发一个**拼点事件** / **判定事件**的操作。

### 视为

1. **视为装备着装备牌**：拥有此装备牌的防具技能，但装备区里**没有**装备牌。（例：〖八阵〗给予的〖八卦阵〗不受"防具牌"相关效果（〖铁骑〗令锁定技无效指向武将技能、〖青釭剑〗无视防具）的对应影响判定——以"装备区里没有防具牌"的事实为准：青釭剑下不能发动八卦阵，因该技能作为防具技能被无效；甘露可选装备区仅一张牌的角色）
2. **\<信息为A的事物> 视为 \<信息为B的事物>**：该事物的该信息**以 B 为准**。（例：〖武神①〗下红桃【麒麟弓】牌名视为【杀】，可用于响应〖享乐〗）

> 注（"视为使用【杀】"类描述）：规则集称为"使用**无对应的实体牌**的【杀】"。虚拟牌与实体牌的对应是规则基石——结算针对虚拟牌的信息进行，被使用/打出的必然是虚拟牌，通常有对应实体牌，有的没有。

## 信息类操作

### 观看

查看相应牌的牌面信息的操作。**不改变牌的可见状态**（看时没注意不能要求再看）。

1. 观看一名角色的手牌默认观看其**所有**手牌
2. 观看暗置的牌时，这些牌依然是暗置的（对除其外的角色依然不可见）

### 展示

在某牌或技能的使用结算中，将背面朝上的牌翻转至正面朝上，然后（**除非**被展示的是手牌且后续效果须对此牌操作）须将此牌翻转回背面朝上的过程；或选择装备区里的牌的过程。**展示过程中牌没有移动**。

◆ 执行展示效果须**同时记录此牌的牌面信息**，此技能中其他即时类效果涉及的此牌信息**皆以记录为准**。（例：〖攻心〗展示时受〖红颜〗影响视为红桃，记录为红桃）

◆ 若一名角色没有手牌，任何角色不能执行令该角色与另一名角色**同时展示手牌**的操作。（例：〖怃戎〗双方都须有手牌）

### 亮出

1. 亮出**牌堆顶**的牌 = 将牌堆顶的牌**置入处理区**（判定即此类）
2. 亮出**牌堆里的一张……牌** = 有则随机将一张移至处理区；没有则没有事发生
3. 亮出**背面朝上放置且不在牌堆**的牌 = 将这些牌翻转至正面朝上

## 其他

### 弃

**失去标记**的操作（针对"枚"为单位的标记）。

### \<一名角色> \<操作>……所有 \<……牌>

若其**没有**……牌，其**不能执行**此操作。

### \<操作> 牌堆/弃牌堆里的 \<一张……牌>

有能操作的……牌 → 从中**随机**操作一张；没有 → 没有事发生。

### 合纵（国战）

出牌阶段内的空闲时间点，能合纵**至多 3 张**带有"合纵"标识的手牌：声明牌名并选择——1. 交给与其势力不同的一名角色（正面朝上移动），然后摸等量的牌；2. 交给一名没有势力的角色。

> 旧项目已作为规则技能实现。
