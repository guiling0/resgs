# 与游戏流程相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。回合/阶段是 TurnEvent/PhaseEvent 与 mainProcess 的规则依据。

---

## 回合（进行游戏的基本形式）

由身份为主公的角色开始，所有角色按**逆时针方向**依次以回合的方式进行游戏。每名角色有一个自己的回合，一名角色的回合结束之后，进行下一个回合的是**其下家**。

> 注：此处只说明**身份局**的回合进行方式，其他模式在后续模式事件定义中说明。此流程即 `Room._mainProcess` 的默认流程。

### ◆ 获得一个额外回合

核心规则（由口述场景提炼）：

1. **插入点**：获得的额外回合在**当前回合结束之后**进行
2. **后获得者先进行**：若本回合内又有角色获得额外回合，新额外回合插在已有额外回合**之前**（场景：E 先获得、D 后获得 → 当前回合结束后 D 额外回合 → E 额外回合）
3. **不挤占额定回合**：额外回合结束后，本轮剩余角色继续正常进行各自的额定回合
4. **轮的归属**：额外回合属于当前轮（本轮会多回合），本轮结束后开始新的一轮

原文场景（从当前回合角色 A 开始逆时针排序 A、B、C、D、E）：

- A 为本轮**最后**回合：E 获得额外回合 → 后续六回合顺序 E→B→C→D→E→A；D 再获得 → 七回合 D→E→B→C→D→E→A
- A 为本轮**首先**回合：E 获得额外回合 → E 额外回合后 B、C、D、E 继续本轮额定回合 → 六回合 E→B→C→D→E→A；D 再获得 → D→E→B→C→D→E→A

关键裁定（〖放权〗〖连破〗例）：

- 额外回合内正常进行各阶段结算：B 额外回合判定阶段【闪电】判定不中 → 实体牌置入 **B 的下家 C** 的判定区（以额外回合角色为基准，而非原回合序）
- 下家获得额外回合 → 额外回合与其额定回合**背靠背**进行
- 武将牌背面朝上的角色获得额外回合 → 于额外回合开始后❺翻面，然后**终止此回合**
- 获得额外回合的效果在其发动时机**即时改写下一轮游戏进行的回合顺序**；同一时机内多名角色可依次发动获得额外回合的技能（按从当前回合角色开始逆时针的响应顺序），后发动者的额外回合排在更前

## 上家 / 下家

一名角色**左/右手边**的角色即其上/下家。

◆ 一名角色**不能成为自己的**上家或下家。

> 实现注：代码区分两组概念——`right`/`left` 表示单纯的右手/左手边玩家（**忽略**不计入座次计算、死亡等因素）；`prev`/`next` 才是本条定义的上/下家（考虑上述因素）。

## 阶段

每名角色的回合分为**六个阶段**：准备阶段、判定阶段、摸牌阶段、出牌阶段、弃牌阶段、结束阶段。

◆ **缺省指代**：技能描述里出现"……阶段"且未写明是哪名角色的哪个回合的——出现在与**时机有关**的描述部分里，默认指**此技能拥有者**的回合的每个该阶段；与时机**无关**的部分里，默认指**发动此技能的回合**的每个该阶段。

◆ "\<一名角色>于……阶段内"中的"……阶段"默认是**其回合**的所有该阶段。

◆ "……阶段内"即从"……阶段开始时（❶）"到"……阶段结束时"的**时间段**。

◆ **额外阶段的生成**：
- 在 A 阶段**之前**获得额外的 B 阶段 = 在"A 阶段之前的阶段结束后"（或"回合开始后❾"）这个时机之后，依次生成：B 阶段开始前 → B 阶段内的各个时机 → B 阶段结束后，再生成 A 阶段开始前
- 在 A 阶段**之后**获得额外的 B 阶段 = 在"A 阶段结束后"（或"回合结束前❶"）这个时机之后，依次生成：B 阶段开始前 → B 阶段内的各个时机 → B 阶段结束后，再生成下一个阶段开始前

◆ **跳过阶段不是执行操作**，而是指拥有"**不生成此阶段内的所有时机**"的状态。若干个连续阶段在 P1 开始之前均已跳过 = 拥有不生成从 P1 开始时起、直至 Pn 结束时为止的所有时机的状态。

◆ 若角色跳过一个回合内的一个阶段，则**不能再次跳过此阶段**。（例：刘禅因【乐不思蜀】判定不中已跳过出牌阶段，不能再以跳过出牌阶段为消耗发动〖放权〗）

> 沮授注（跳过后的时机停留）：角色于某个时机跳过阶段后，**仍然停留在此时机**，此时机所有结算完毕才进入下一个时机。例：张郃-夏侯渊于出牌阶段开始前发动〖巧变③〗跳过出牌阶段，移动装备牌后仍处于"出牌阶段开始前"（而非弃牌阶段开始前）；已跳过一次出牌阶段，不能再发动〖神速②〗跳过；此时机结算完毕后进入弃牌阶段开始前。

## 终止……流程/回合

在……流程/回合中的时机 a 终止此流程/回合 = **结束 a 时机**，且**不会生成**此流程/回合中从时机 a 之后直至此流程/回合结束的**所有时机**。

## 结束……阶段/回合

此效果执行完毕会终止一切结算，**进入**"……阶段结束时"/"回合结束前❶"这个时机。

> 终止 vs 结束的区别：**终止**不再生成后续任何时机（含收尾时机）；**结束**是跳转到收尾时机（收尾时机正常进行）。

玩家在游戏中的**操控对象**。
