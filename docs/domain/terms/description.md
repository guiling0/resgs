# 与牌面描述相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。解析/编写技能描述时的标准参照文档。

---

## 技能标签

| 标签 | 定义 | 实现（SkillTag） |
|---|---|---|
| **锁定技** | 令带有此标签的技能**不被克制**，目前没有其他任何作用 | `Lock` |
| **限定技** | 带有此标签的技能于一局游戏内**发动次数上限为 1** | `Limit` |
| **觉醒技** | 视为附带"锁定技"和"限定技"标签 | `Awake`（实现中自动附加 Lock + Limit 语义） |
| **主公技** | 若一名角色的武将牌有此标签且身份为主公 → 拥有；不为主公 → 没有。但**获得**带有此标签的技能则不受身份限制 | `Lord` |
| **阵法技** | 4 项特点：触发类必须发动 / 状态类必须影响 / 角色数 < 4 无效 / 以座次关系为条件 | `Array` |
| **奥秘技** | 处于**暗置**状态发动——**不声明**发动此技能，直接执行效果 | `Secret` |
| **主将技/副将技** | 此武将牌为主/副将时，带有此标签的技能才有效 | `Head` / `Deputy` |

注：觉醒技和限定技拥有各自的基础动画（`EffectData` 中区分），详见代码注释。

## 牌描述中的短语

### 可

1. 对于**有消耗**的触发类技能：**消耗前**的"可"表示主语拥有选择**是否发动此技能**的权利；**效果前**的"可"表示主语拥有选择**是否执行此效果**的权利
2. 对于**没有消耗**的触发类技能：**唯一的效果前**的"可"表示主语拥有选择**是否发动技能**的权利

> 实现：`EffectData.settings.forced`（`'mute'` 锁定自动 / `'cost'` 询问后发动），详情参照代码注释。

### \<角色> 的\<……（与区域无关的限制条件）牌>

即其**手牌区和装备区里**的……牌。

- 例：司马懿发动〖反馈〗不能选择邓艾武将牌上的"田"
- 例：马岱发动〖寒冰剑〗弃置曹冲的牌时不能弃置判定区里的牌
- 例：小乔的手牌和装备区里的黑桃牌花色受〖红颜〗影响，**判定区里的黑桃牌不受影响**

### 此牌

一个技能/牌的描述中提到的"此牌"——此前描述的某个效果中提到过的一张牌。若此前因角色插入发动其他技能使这张牌所在的区域发生过改变，则"此牌"**不存在**。

### 以此法 / 未以此法

- **以此法**：以此次发动的技能中表述的方法
- **未以此法**：于此局游戏内未以此技能中表述的方法

## 符号

| 符号 | 含义 |
|---|---|
| **〖〗** | 标识**技能名**。如 〖八卦阵〗= 防具技能 |
| **【】** | 标识**游戏牌的牌名**。如 【八卦阵】= 防具牌 |
| **" "** | 标识角色武将牌上的游戏牌/武将牌旁的游戏牌/仓廪里的牌/府库里的牌（以"张"为单位）或**标记**（以"枚"为单位）。◆ 若技能中提到的"X"标记未说明是哪名角色拥有，默认是指**其拥有**的"X"标记 |
| **{ }** | ① 函数表达式的符号之一；② 表示句子内部的逻辑层次 |
| **/** | 出现 1 次 = 两个技能因结构一样合并写成一个；出现 ≥2 次 = 多个技能合并，被"/"分开的词按先后顺序**一一对应**与各自语句组合 |
| **▶** | 连接消耗和效果——消耗在左，效果在右 |
| **▷** | 连接两个效果——只有执行了左边的效果才能执行右边的 |
| **→** | 提示技能的**延时类效果**出现在"→"右边 |

## 操作关键词

### 转移

**目标转移**：角色 A 成为一张牌的目标时将此牌转移给 B = 取消此目标 + 生成与 B 对应的新目标 + 从当前回合角色逆时针编号 [T1, T2, ...] + 重新排序未生成过"成为目标时"事机的目标 + 若为延时锦囊牌则将实体牌置入 B 判定区。

**伤害转移**：将伤害的承受角色改为 B = 先防止 A 受到的伤害，然后对 B 造成**同来源、同渠道、同属性**、伤害值等于 A 于转移前受到的伤害值的伤害。

关键裁定（原文示例的要点）：

- 转移后的伤害在 B 处正常触发 B 侧技能（〖藤甲〗〖狂风〗对转移来的火焰伤害生效，2 点 → 3 点）
- 转移可使伤害来源与承受者为同一角色（〖刚烈〗伤害被〖天香〗转移回夏侯惇自己，其再发动〖刚烈〗的目标是自己）
- 转移后的伤害保持渠道（〖天香〗转移【杀】的伤害后，〖悲歌〗仍可对 B 发动，因为渠道仍是此【杀】）
- 转移目标结算时机独立（多目标结算中转移给后续目标的伤害立即结算，受目标自身装备/技能影响）

### 依次 \<操作> \<X> 张……牌

操作一张……牌，然后重复 (X-1) 次。**注意**：没有"依次"关键词的操作均指一次性同时操作（例：法正〖眩惑〗一次性获得两张牌 → 失去两张牌后❷只能发动**一次**〖屯田①〗）。

### 需 / 须 / 并

- **需**：角色拥有**选择权**（如何进行响应）
- **须**：**强制**角色执行操作
- **并**：连接两个操作——**同时执行**，若其中一个不能执行，另一个也不能执行

### 扣减体力

失去体力和受到伤害均会导致角色扣减体力。

### A 令 B

指令由 A 发出，动作由 B 执行。B 为角色且不能执行此操作 → 不能令，**但弃置例外**：只要 B 有符合弃置要求的牌就能令。B 为多名角色 → 只要有一名能执行就能令。

### 选择：1.……2.……

从多个选项中选择任意**一项**执行。包含消耗的选项 → 不能选择无条件执行的消耗不能执行的选项；不包含消耗 → 不能选择所有无条件执行的效果均不能执行的选项。

### \<多名角色> 各 \<执行一个操作>

先选择所有符合条件的角色，然后依次执行。**角色选择后即便条件不再满足，仍须执行**。（例：韩当发动〖解烦〗确定完邓艾和张角后，张角至 A 的距离变化仍须执行选择效果）

### 也成为 \<一张牌> 的目标

生成对应新目标加入目标列表，逆时针编号排序。◆ 不是合法目标的角色**不能**执行；**不受额定目标数上限限制**。

### 因 \<执行一个操作> / 因 \<一名角色> \<执行一个操作>

前者 = 无论**任何角色**执行此操作均满足条件；后者 = **指定角色**执行才满足。

## 使用/打出者 与 来源 与 渠道

### 使用/打出者

一张牌的使用/打出者即使用/打出此牌的角色。

◆ 若使用者**改为** B：在之后的使用流程中此牌视为 B 使用，但视为 A **使用过**此牌而 B **未使用过**。因此只有 A 的使用次数被消耗。

◆ 发动条件与使用者信息有关的技能时，**使用者已死亡也能调用到其信息**。

### 来源

造成伤害的角色。来源确定以**实际造成伤害的因果关系**为准（例：刘备发动〖激将〗使用【杀】→ 来源为刘备）。

◆ 伤害结算中若来源已死亡，**视为此伤害没有来源**。

◆ 渠道为牌的伤害来源发生改变，**不会改变此牌的使用者**。

### 渠道

伤害的渠道根据**造成伤害的原因**确定：

1. 因执行牌/技能的效果 → 渠道为此牌/技能
2. 因连环传导 → 渠道与触发连环的伤害相同
3. 因转移牌/技能效果伤害 → 渠道与被转移的伤害相同
4. 因转移连环伤害 → 渠道与被转移的伤害相同

> 注："渠道"的意义在于区分牌 vs 技能造成的伤害（不少技能需要区分）。实现中渠道只能提供牌（技能造成的伤害通过 `skill` 属性表示）。
> 例：装备〖古锭刀〗的连环传导结算——对 B 的传导伤害时❶不能发动〖古锭刀〗（渠道相同，但时机是传导而非使用牌）

### 造成（或受到）……点普通/火焰/雷电伤害

若 A 已死亡，执行"A 对 B 造成伤害"的效果 → B 受到**无来源**的该伤害。

## 属性伤害 / 连环伤害

- **普通伤害**：不具有属性的伤害
- **属性伤害**：火焰伤害（火焰属性）或雷电伤害（雷电属性）
- **连环伤害**：不会触发连环传导的属性伤害。判断方法：因连环传导/转移连环伤害而造成的伤害 = 连环伤害；其他所有属性伤害均不为连环伤害

> 注：因属性伤害触发铁索传导后，非传导起点的角色受到的都是连环伤害。每个受到连环伤害的角色均会进行**一次独立的伤害流程**。

## 体力相关判定

### 已/未受伤

体力值 < 体力上限 → **已受伤**；= 体力上限 → **未受伤**。

### \<一名角色> 回复 \<X> 点体力

令 Y = 已损失体力值。Y = 0 → 不能执行；≥ X → 正常执行；0 < Y < X → 执行但改为回复 **Y** 点体力。

### \<一名角色> 将体力回复至 \<X> 点

令 Y = 体力，Z = 体力上限。Y = Z 或 Y ≥ X → 不能执行；Y < Z 且 Y < X → 回复 **min{X,Z} - Y** 点体力。

> 例（负体力计算）：体力上限 1 的庞统受 2 点伤害至体力 -1，发动〖涅槃〗"将体力回复至 3 点" → 回复 min{3,1} - (-1) = **2** 点，即将体力回复至 1 点。

| **其他角色** | 除"你"外的角色 |

## 其他操作/状态定义

### 可见

一张牌对一名角色可见 = 无论正面/背面朝上，其都能随时观看此牌。一张牌可见 = **每名角色**都能随时观看此牌。

> 注：旧项目有实现，新项目暂未实现，不打算延续旧实现。**日后讨论**。

### 杀死

一名角色因受到**有来源**的伤害而进入濒死结算死亡 → 此来源即杀死该角色的角色。

### 相邻 / 围攻 / 队列 / 大势力 / 小势力

- **相邻**：两名角色间没有其他角色
- **围攻**：上家下家势力相同且与该角色不同 → 被围攻。上家下家为围攻角色
- **队列**：≥2 名连续相邻且势力相同的角色处于同一队列
- **大势力**：角色数最大且 > 1 的势力
- **小势力**：大势力存在时，除大势力外的势力/角色

### 不计入距离的计算（状态类型）

A 不计入距离计算 → 其他角色至 A 距离不计算；A 至其他角色距离不计算；计算第三者距离时视 A 已离场。

### 不计入座次的计算（状态类型）

A 不计入座次计算 → 与所有角色不相邻；不处于任何围攻/队列中；判断围攻/队列/阵法召唤时视 A 已离场；B 的上/下家为 A 时改为 A 的左/右手边角色；A 没有上/下家。

### 阵法召唤

5 个条件（缺一不可）：①有势力且不为野心家 ②有一张明置武将牌有阵法技 ③存在无势力角色 ④同势力角色数 < 玩家数一半 ⑤根据阵法技类型（围攻/队列）：

- **围攻**：上家势力不同且上上家无势力，或下家势力不同且下下家无势力
- **队列**：顺时针/逆时针路径至无势力角色，路径上无不同势力角色

**结算顺序**（核心算法）：①若满足队列条件 b（逆时针方向），从 A 开始逆时针检测第一名无势力角色，若明置后仍满足条件可令其明置，明置后重复 ②若满足队列条件 a（顺时针方向），同方向逐一检测明置。围攻类同理（下家方向优先于上家方向）。

> 注：正向枚举展开极长（A→U 每步检测）。实现只需按上述①②算法逐角色循环检测，无需硬编码。

### 军令

角色 A 选择军令 = 系统从下列**六项操作**中随机选择两项，A 从这两项中选择一项作为军令：

1. 执行军令者对 A 选择的除执行军令者外的一名角色造成 1 点普通伤害
2. 执行军令者摸一张牌，交给 A 两张牌
3. 执行军令者失去 1 点体力
4. 执行军令者于当前回合内不能使用或打出手牌，且其所有未带有"锁定技"标签的武将技能于当前回合内无效
5. 执行军令者叠置，于当前回合内不能回复体力
6. {若执行军令者有手牌，其选择一张手牌。若其装备区里有牌，其选择其中的一张。其弃置除其以此法选择的牌外的所有牌}

A 令 B 选择是否执行军令 = A 选择军令，然后 B 选择是否执行。若 B 选择执行，**无论 B 是否能执行此军令的所有操作，均算作是执行了此军令**。

> 注：旧项目实现为 CommandEvent（另有与军令无区别的 MiaoJiEvent）；**新项目不准备以事件实现军令类机制**。

### 失去 \<一名角色> 的所有武将技能

失去除**因其他角色的技能的状态类效果而拥有**的武将技能外的所有武将技能。

### 转化

下列情形均称为使用/打出**转化的牌**：

- 在使用/打出一张牌的流程中，发动时机为"**需要使用/打出牌时❸**"的技能
- 执行时机为"需要使用/打出牌时❸"的技能的**延时类效果**
- 通过发动〖国色①〗、〖默识〗、〖逆乱〗、〖慎断〗或〖伺盗〗来使用/打出此牌
- 通过执行〖默识〗的延时类效果来使用/打出此牌

> 实现：是否转化由 `EffectData.settings.viewas`（boolean，默认 true，只在需要使用/打出时的技能有效）决定，**不按上述规则枚举**。

### 牌堆里的第……张 \<一张牌>
