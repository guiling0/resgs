# 与事件结算相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。事件系统（EventProcess/EventManager）与 M2/M3 事件实现的直接规则依据。

---

## 事件

角色操作牌、发动一个技能或进行一次响应，即产生一个事件。事件是**若干个相关流程的总和**，可能被其他事件响应。

## 结算

**处理一个事件的过程**。

## 时机

时机是**一个瞬间**。一个事件发生时会产生若干个时机。一个回合或一个事件的流程里的所有时机是**按照顺序依次生成并进行处理**的。

## 流程

事件在合理的时机**插入发生**后所进行的处理过程。

## 响应

**一个事件对另一个事件加以影响的形式。**

◆ 响应关系的判定：

- 目标为【杀】的【闪】 = 因响应此【杀】而被使用
- 目标为普通锦囊牌的【无懈可击】 = 因响应此普通锦囊牌而被使用
- 因执行【借刀杀人】的效果而使用的【杀】 = 因响应此【借刀杀人】而被使用
- 因执行【决斗】/【万箭齐发】/【南蛮入侵】的效果而打出的【杀】/【闪】/【杀】 = 因响应对应牌而被打出

◆ "角色不能响应"的语义：

- 不能响应【杀】 = 此【杀】不是其使用【闪】的合法目标
- 不能响应不为【决斗】【借刀杀人】【万箭齐发】【南蛮入侵】的普通锦囊牌 = 此牌不是其使用【无懈可击】的合法目标
- 不能响应【决斗】/【万箭齐发】/【南蛮入侵】 = 不能因执行其效果而打出【杀】/【闪】/【杀】，且此牌不是其使用【无懈可击】的合法目标
- 不能响应【借刀杀人】 = 不能因执行其效果而使用【杀】，且此牌不是其使用【无懈可击】的合法目标
- 除此之外的牌，**不能令角色不能响应此牌**

## 无效

**1. 一张牌对一个目标无效**：不会生成"对此目标使用结算开始时""对此目标生效前""对此目标生效时""对此目标生效后"这**四个时机**。

> 注（无效 vs 取消）：对目标无效使此牌失效，但使用结算基本照常进行，仅吃掉后期几个时机；**目标被取消则之后所有时机都被吃掉**。例：马超-赵云对于吉-华佗使用【杀】，于吉-华佗在成为目标时发动〖千幻②〗取消目标 → 〖铁骑〗的时机（指定目标后）就没有了。

**2. A 的……技能于一个时间段内无效**：所有角色于此时间段内**不能发动** A 的……技能，且 A 的……技能于此时间段内**不能产生影响**。反之称为有效。

> 例：〖青釭剑〗效果持续时间内，任何角色弃置或获得 B 装备区里的【白银狮子】，B 在失去【白银狮子】前❷均不能发动〖白银狮子②〗（对所有人无效）。

## 取消

**1. 基本牌/普通锦囊牌**的使用流程中，在"指定目标 Tm 时"或"成为目标 Tm 时"这个时机的处理过程中被响应取消 → 将 Tm **移出目标列表**并**终止此时机**。

> 例：关羽-张飞对于吉-贾诩使用【杀】被〖千幻②〗取消目标后，关羽-张飞在此【杀】**结算结束后❷仍能发动〖勇决〗**——取消只终止当前时机并移除目标，使用流程的收尾时机照常进行。

**2. 延时锦囊牌**的使用流程中，在"成为目标 Tm 时"的处理过程中被响应取消 → 同上。

**3. 移动流程**中，在"移至目标区域前❶/❷"的处理过程中被技能响应取消部分牌 B → 此后流程中以剩余的牌作为此次移动的牌，B 不再是此次移动的牌。**若全部取消（A=B），则防止此次移动**。

◆ 若在因一个操作而进行的移动结算中取消部分牌的移动，则**此操作执行完毕，但未对这部分牌执行过此操作**。

## 无视

A 无视 B 的防具技能 = 在 **A 使用牌对 B 结算 / A 使用技能结算 / B 受到来源为 A 的伤害结算**的过程中，B 的防具技能无效；但在上述过程中**插入**的、除 A 外的角色的结算过程中（或 B 受到来源不为 A 的伤害时），B 的防具技能**有效**。

> 注（无视 vs 令无效）：〖陷阵〗无视防具技能——防具技能**仅在高顺眼中无效**，其他人眼中有效；〖青釭剑〗发动后防具技能**在所有人眼中无效**。

关键裁定：

- 〖陷阵〗后【杀】被〖流离〗转移给被陷阵者 → 其〖藤甲①〗仍不触发（结算属于高顺使用牌的结算）
- 被陷阵者自己打出【白银狮子】对应实体牌（因〖鬼道〗）→ 移动是其**自己**操作的，失去前❷**能**发动〖白银狮子②〗
- 第三者对被陷阵者造成伤害（如张角〖雷击〗）→ 来源不为高顺，防具**有效**
- 高顺的火【杀】经连环传导伤害到被陷阵者 → 来源仍为高顺，〖藤甲②〗**不触发**

## 防止

**1. 伤害/失去体力**：在对一名角色进行的伤害/失去体力结算中防止 = **终止此伤害/失去体力流程**。

◆ 若防止 A 对 B 造成的伤害，则 **A 未造成过此伤害，B 也未受到过此伤害**。

◆ 若伤害值为 X 且 X ≤ Y，执行"伤害值 -Y"的效果会**改为防止此伤害**。

关键裁定：

- 【护心镜】防止转移来的伤害后，〖天香〗摸牌效果的条件（体力值 < 上限）与最终是否受到伤害无关，满足则仍执行
- 〖天香〗把伤害转移给来源自己 = 防止自己受到的属性伤害 → **没有重置或触发连环的时机**
- 〖寒冰剑〗防止〖疠火①〗参与的伤害 = 终止伤害流程 → 〖疠火①〗"失去 1 点体力"效果**没有执行的时机**

**2. 移动**：防止这些牌的此次移动 = 终止此移动流程。◆ 因操作进行的移动被防止 → 此操作执行完毕，但未对此次移动的牌执行过此操作。

**3. 牌状态改变**：防止此改变 = 终止此牌状态改变流程。

## 起点

受到**不为连环伤害的属性伤害**的、**处于连环状态**的角色，即此伤害的起点（连环传导的起始角色）。

## 实现映射

| 用语 | 实现 |
|---|---|
| 防止（伤害） | `DamageEvent.prevent()`（仅特定时机可调用）✅ |
| 防止（移动） | `MoveCardEvent.preventMove()` ✅ |
| 取消（移动部分牌） | `MoveCardEvent.cancel(cards)`（全取消自动转 preventMove）✅ |
| 防止（状态改变） | `ChangeStateEvent` prevent ✅ |
| 无效（对目标） | M2 UseCardEvent：targetList 的 `invalid` 标记（跳过四个生效时机） |
| 取消（目标） | M2 UseCardEvent：移出目标列表 + 终止当前时机 |
| 连环传导/起点 | `DamageEvent.ts` 中 TODO（连环伤害传导），按本文档与 [description.md](description.md) 连环伤害定义实现 |
| 无视（按观察者失效） | 未实现——`Skill_Invalidity` 是全局失效，需要**来源作用域**的失效机制（见 pending-impl） |
