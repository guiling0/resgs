# 与操作武将牌相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。

---

## 横置 / 重置 / 连环状态

- **横置**：武将牌竖放的角色将其武将牌**横放**的操作
- **重置**：武将牌横放的角色将其武将牌**竖放**的操作
- **连环状态**：武将牌横放的角色即处于"连环状态"

### ◆ 触发连环

当一名角色因受到**属性伤害**而扣减体力**前**，若其处于连环状态，其须**重置**。然后若此属性伤害**不是连环伤害**且此时还有其他处于连环状态的角色，当此伤害结算结束后会触发连环：从当前回合角色开始**逆时针**依次检测——若处于连环状态，其受到与此属性伤害**同来源、同渠道、同属性、同伤害值**的伤害。

关键裁定（原文连环传导四例要点）：
- 传导途中装备/技能继续触发（〖藤甲②〗对传导伤害增减、重置顺序不影响后置角色）
- 传导中〖天香〗转移伤害 → 转移后的伤害仍为同一轮传导中的一环（转移对象重置后不重复结算传导）
- 多目标结算中被流离至连入方 → 各目标伤害与传导传递交织结算，"重置后进行到下一个角色"规则不变
- 连环传导中吕布对自己造成的伤害 → 仍可发动〖狂暴②〗（来源=自己，不因传导改变来源）

## 翻面 / 叠置

- **翻面**：角色将其正面朝上的武将牌翻转至**背面朝上**（或反之）
- **叠置**：处于**平/叠置状态**的角色改为处于**叠/平置状态**（副将在上主将在下 = 叠置；副将在左主将在右 = 平置）

> 实现：`PlayerState.skip` 统一代表"是否跳过回合"——翻面和叠置在代码层合并（旧项目 conflate 行为，延续）

## 复原

角色复原 → 依状态分支：

1. 武将牌背面朝上（或处于叠置状态）**且**处于连环状态 → 先重置，然后翻面（或叠置）
2. 背面朝上（或叠置状态）**且**未处于连环状态 → 翻面（或叠置）
3. 正面朝上（或平置状态）**且**处于连环状态 → 重置
4. 正面朝上（或平置状态）**且**未处于连环状态 → **不能执行**

例：庞统发动〖涅槃〗复原 → 翻面后，陈群能发动〖法恩〗令庞统摸牌（先重置重置连环 → 翻面；翻面发生在连环清理之后，符合〖法恩〗时机）。

## 明置 / 暗置

- **明置**：将一张背面朝上的武将牌翻转至正面朝上（处于"明置状态"）
- **暗置**：将一张正面朝上的武将牌翻转至背面朝上（处于"暗置状态"）

◆ 没有处于明置状态的武将牌的角色：**没有性别**；只有一张明置 → 性别与**此武将牌**相同；两张均明置 → 与**主将**的性别相同。角色于确定自己的势力前**没有势力**。

◆ 每名**野心家**的势力均是**独立**的——与其他所有势力均不同（包括其他野心家）。

◆ 没有势力的角色与**自己**势力相同，但**不能**判断其他角色与其势力是否相同。

◆ 没有性别的角色**不能**判断其他角色与其性别是否相同。

◆ 角色可不发动处于暗置状态的武将牌的**强制发动**的技能；角色处于暗置状态的武将牌的**状态类技能无效**。

> 关键裁定（〖勇决〗获得后明置限制）：糜夫人-甘夫人发动〖存嗣②〗令关羽（暗置）-张飞（暗置）获得〖勇决〗→ 关羽-张飞在自己的出牌阶段出杀后能发动〖勇决〗（不能因此明置——〖勇决〗是角色的武将技能，而非关羽或张飞的主将/副将牌的技能），但糜夫人-甘夫人出杀后关羽-张飞**不能**发动〖勇决〗（不是发动者自己的回合）。

## 移除

将被移除的武将牌置入**武将牌堆**。被移除武将牌的角色用一张"**士兵牌**"代替：士兵牌的性别、势力与被移除的武将牌相同，但**没有技能和姓名**，也不能作为主将或副将（操作其主将/副将牌须以操作士兵牌来代替）。

## 变更

角色变更 = **明置所有处于暗置状态的武将牌**，然后：将武将牌堆里标识的势力与**其武将牌上标识的势力相同**的**三张随机武将牌**展示给其，其选择一张作为副将的新武将牌且**正面朝上放置**，同时将其副将的原武将牌（若有）置入武将牌堆。
