# 与数值相关的用语

> 领域权威定义。来源：用户口述（2026-07-18）。数值公式类用语——手牌上限/距离/攻击范围/额定摸牌数/点数等使用统一的"初值 + 修正值 → 终值"模型。

---

## 体力四值

| 用语 | 定义 | 实现 |
|---|---|---|
| **体力上限** | 角色的体力牌上的所有勾玉数 | `PlayerState.maxhp` |
| **体力值** | 角色的体力牌上露出的勾玉数（最小为 0） | `Player.inthp` |
| **已损失的体力值** | 角色的体力牌上未露出的勾玉数 | `Player.losshp`（= maxhp - inthp） |
| **体力** | 一个数值。角色的初始体力等于其体力值。**注意：角色的体力有可能小于 0** | `PlayerState.hp` |

## 手牌上限

初值 Ao、修正值 ΔA1…ΔAn、终值 Af。影响效果分三类：

1. "A 的手牌上限**为** X"——改变 Ao 的计算方式
2. "A 的手牌上限**视为** X"——改变 Af 的计算方式
3. "A 的手牌上限 **+X / -X**"——产生 ΔA

计算：
- 未受效果 1 影响：Ao = A 的体力值；受效果 1 影响：Ao = X
- 受效果 2 影响：Af = X
- 未受效果 2、3 影响：Af = Ao
- 受效果 3 且未受效果 2 影响：**Af = max{Ao + ΣΔA, 0}**

实现：`StateEffectType.MaxHand_Initial`（效果1）/ `MaxHand_Fixed`（效果2）/ `MaxHand_Correct`（效果3）；另有 `MaxHand_Exclude`（某些牌不计入手牌上限——三类之外的附加机制）。

## 伤害值基数

牌或技能描述中，"造成 X 点伤害"和"受到 X 点伤害"这两个操作中的"X"。

## 回复值基数

牌或技能描述中，"回复 X 点体力"这个操作中的"X"。

## 距离

角色 A 至**自己**的距离终值为 **0**。A 至另一名角色 B：初值 Lo、修正值 ΔL1…ΔLn、终值 Lf。影响效果分两类：

1. "A 至 B 的距离**视为** X"——改变 Lf 的计算方式
2. "A 至 B 的距离 **+X / -X**"——产生 ΔL

计算：
- 未受效果 1 影响时，Lo 按座次环计算：从前者开始按顺时针或逆时针方向连接至后者所需的**最少箭头数**（口述来源附图，文字化：座次环上顺/逆时针两个方向取最短步数）。例：ABCDEF 六人环中，D至A=3、D至B=2、D至C=1、D至E=1、D至F=2
- ◆ **一名角色死亡则不再参与距离初值的计算**
- 受效果 1 影响：Lf = X
- 未受效果 1、2 影响：Lf = Lo
- 受效果 2 且未受效果 1 影响：**Lf = max{Lo + ΣΔL, 1}**

**注意：A 至 B 与 B 至 A 的距离终值会因受到不同效果的影响而不同（距离不对称）。**

实现：`StateEffectType.Distance_Fixed`（效果1）/ `Distance_Correct`（效果2）；`NotCalcSeat`/`NotCalcDistance` 为"不计入座次/距离计算"的附加机制。

## 攻击范围

初值 Ao：装备区里**没有武器牌 → Ao = 1**；有武器牌 → Ao = 此武器牌上标识的攻击范围数值。修正值 ΔA1…ΔAn、终值 Af。影响效果分两类：

1. "A 的攻击范围**无限**"——改变 Af 的计算方式
2. "A 的攻击范围 **+X / -X**"——产生 ΔA

计算：
- 未受效果 1、2 影响：Af = Ao
- 受效果 1 影响：Af = **+∞**
- 受效果 2 且未受效果 1 影响：**Af = max{Ao + ΣΔA, 1}**

◆ **A 的攻击范围内**：是 A 与 B 之间距离关系的一种。若 A 的攻击范围终值 ≥ A 至 B 的距离终值，则称 B 在 A 的攻击范围内。注意：

1. 若 A 的攻击范围无限，则除 A 外的所有角色均在 A 的攻击范围内
2. **角色不在自己的攻击范围内**

实现：`StateEffectType.Range_Initial` / `Range_Correct`（效果2）/ `Range_Fixed`（效果1，无限=∞）；`Range_Within`/`Range_Without`（视为在/不在攻击范围内——附加机制）。

## X、Y、Z（自然数变量）

游戏中的自然数变量。

◆ 变量出现在**不等式**里——表达一个条件；变量作为**集合的元素**——执行相关操作的角色能在此集合表示的取值范围内自行取值；变量出现在**等式**里——执行相关操作的角色须通过计算得到取值（若此变量是伤害值，取值即截至执行相关操作时能计算得到的伤害值）。

## \<数值X> 与 \<数值Y> 之差

即 **|X - Y|**（绝对值）。

## 等量的……

在一张牌或一个技能的牌面描述中，"等量的……"中的数值由**此文字前最近的一个非固定数量**决定。

## ……的势力数 / 角色数

（某条件下的势力数/角色数）**已死亡的角色不参与这些数值的计算**。

## \<一个数值> 最大 / 最小

**允许多名角色并列**最大/最小，其中的每名角色均为该数值最大/最小的角色。

## 至多 X / 至少 X

- **至多 X**：执行相关操作的角色自行决定取值，范围为**大于 0 且不大于 X** 的任意自然数
- **至少 X**：自行决定取值，范围为**不小于 X 且不大于此变量的最大值**的任意自然数

## 任意数量

执行相关操作的角色自行决定取值，范围为**大于 0 且**不大于此变量的最大值的任意自然数（**不能取 0**，用户裁定 2026-07-18；与"至多X"仅上界不同）。

## 额定摸牌数

一名角色于当前回合的摸牌阶段内因游戏固定的流程额定获得的手牌数。**初值为 2**。修正值 ΔA1…ΔAn、终值 Af。影响效果分两类：

1. "A 的额定摸牌数**改为 0**"——改变此摸牌阶段 Af 的计算方式
2. "A 的额定摸牌数 **+X / -X**"——在此摸牌阶段产生 ΔA

计算：
- 未受效果 1、2 影响：Af = 2
- 受效果 1 影响：Af = 0
- 受效果 2 影响：**Af = max{2 + ΣΔA, 0}**

实现：非 StateEffect 查询，为**事件数据字段修改**模式（旧项目 `data.ratedDrawnum--`，如裸衣消耗）。

## 玩家数

参与一局游戏的玩家数。**玩家操控的角色离场不会改变玩家数**。

## 目标对应的角色数

若目标对应的角色已死亡，这些目标对应的角色数计为 **0**。

> 注：目标对应的角色数在结算过程中可能变化，检测时**一定检测当前时刻**的目标对应的角色数。例：场上逆时针 A、B、界陆逊三人，A 使用【南蛮入侵】目标对应角色数为 2；B 受伤死亡后变为 1；对界陆逊生效时其可发动〖谦逊①〗。

## 游戏牌 ID

每一张游戏牌都有独立的 ID，**不存在 ID 相同的两张游戏牌**。

- 实现：`GameCardId`（number），区域中以 ID 列表存放（`cardAreas: ArraySchema<number>`）

## 点数（终值计算）

> 点数的牌面定义见 [card-face.md](card-face.md)。本条为受效果影响后的终值计算。

初值 Po、修正值 ΔP1…ΔPn、终值 Pf。影响效果分两类：

1. "A 的点数**视为** X"——改变 Pf 的计算方式
2. "A 的点数 **+X / -X**"——产生 ΔP

计算：
- 未受效果 1、2 影响：Pf = Po
- 受效果 1 影响：Pf = X
- 未受效果 1 且受效果 2 影响，记 S = Po + ΣΔP：**S < 1 → Pf = 1；1 ≤ S ≤ 13 → Pf = S；S > 13 → Pf = 13**（钳制到 [1, 13]）
