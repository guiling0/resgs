# 濒死事件 & 死亡事件（DyingEvent & DeathEvent）

> 领域权威定义。来源：用户口述（2026-07-18）。实现参照新项目 `DyingEvent.ts`（含 DyingEvent 与 DeathEvent 两个类）与旧项目 `event/types/event.die.ts`。

---

## 濒死事件（DyingEvent）

濒死结算中：**进入濒死状态时 → 进入濒死状态后 → （连续若干个）处于濒死状态时**。

### （1）进入濒死状态时（dying_entry）

能发动：〖补益〗、〖陈情〗、〖逢亮〗、〖绝境②〗、〖七哀〗、〖杀绝〗、〖随势①〗、〖兴衰〗、〖招祸〗。

◆ 若有角色发动上述技能之一，且此技能的结算流程结束后 A 的体力值 **> 0** → A 存活，**终止濒死结算**。

### （2）进入濒死状态后（dying_entry_after）

能发动：〖完杀（国）〗。

### （3）（连续若干个）处于濒死状态时（dying）

能发动：〖不屈①〗、〖醇醪②〗、〖伏枥〗、〖激诏〗、〖救主〗、〖涅槃〗、〖仁心（旧将）〗；能使用的牌：【酒】（使用方法②）、【桃】（使用方法②）。

◆ **技能首轮限定**：拥有这些技能的角色在**一个濒死流程中，只有在第一次轮到其进行响应时才能发动这些技能**（桃/酒的使用不受此限）。（法正例：曹冲第二轮只能用【桃】不能再发〖仁心〗；庞统首轮拒发〖涅槃〗后新时机中不能再发）

**响应循环规则**：在一个"处于濒死状态时"的处理过程中，角色 B 使用一张牌或一个技能响应后，若 A 的体力值：

- **> 0** → 终止濒死结算，A 存活
- **= 0 且有能继续响应的角色** → 终止此时机，进入**新的"处于濒死状态时"**。简化结算：新时机中**并非**所有角色从当前回合角色开始逆时针响应，而是**从 B 开始按逆时针方向排序至当前回合角色的上家为止**的这些角色依次响应
- **= 0 且无人能继续响应** → 终止此时机，A **死亡** → 进行 A 的死亡流程 → 死亡流程结束后继续濒死流程（即濒死结算结束）

> 周泰例（单角色结算原则）：轮到自己响应时先发武将技〖不屈①〗→（若"创"重复被弃、此次结算未回复过体力）→ 可再发装备技 → 仍未回复过体力 → 最后能对自己用【桃】/【酒】。用桃后体力仍 ≤0 → 进入新时机（从周泰开始至回合角色上家止），周泰可先发武将技但不能再发〖不屈①〗。

### 濒死结算结束后（dying_end）

能执行：〖补益（国）〗、〖黩武〗的延时类效果、〖绝境②〗、〖狂袭〗的延时类效果、〖兴衰〗的延时类效果、〖许身〗。

## 死亡事件（DeathEvent）

### 前置处理（死亡结算开始前）

1. 若其姓名为**左慈** → 性别改男、势力改群。确认其性别和势力
2. 若其因受到**有来源**的伤害而死亡 → **来源杀死过该角色**（见 [description.md](../terms/description.md) 杀死）
3. **国战**：将死亡角色所有暗置武将牌**翻转至正面朝上**（**并非明置**——不触发明置相关效果，蔡文姬例：不受〖祸水②〗影响、死亡时能发〖断肠〗）。君主死亡 → 同势力其他角色全部改野心家；无势力者按 a/b/c 规则确定势力（同 [change-state.md](change-state.md) 势力确定）。最后全场同势力 + 数量与死亡之和 ≤ X + 无君主 → 该势力全员获胜

◆ **死亡角色于此流程中未列举的触发类技能于此流程中无效**。（步练师死亡被〖行殇〗拿牌 → 失去【白银狮子】前❷不能发〖白银狮子②〗）

首先若其**体力 > 0 → 将体力改为 0**。（〖武魂〗判定死亡例：步练师死亡时体力值=0，〖缠怨〗检测不成立）

### （1）确认身份前

暂时没有作用（技能）。

然后将其暗置的**身份牌翻转至正面朝上，确认其身份**。若满足游戏结束条件 → **终止一切结算和流程，结束游戏，宣布获胜的角色**；不满足 → 游戏继续。

### （2）死亡时（death）

能发动：〖藏机〗、〖断肠〗、〖挥泪〗、〖荐杰③〗、〖绝响〗、〖送丧〗、〖肃资〗、〖随势②〗、〖武魂②〗、〖行殇〗、〖延祸〗、〖应势〗的延时类效果、〖追忆〗。

然后其**离场**，依次处理：

- **Ⅰ. 系统同时处理**：a. 弃置其装备区和手牌区里的所有牌 + 判定区里的所有牌置入弃牌堆；b. 武将牌上和武将牌旁的所有牌置入弃牌堆；c. **弃其所有标记**；d. 所有武将牌置入武将牌堆
- **Ⅱ.** 若杀死其的角色**不为其自己** → 杀死其的角色**执行奖惩**（身份局：杀反贼摸三张/杀忠臣弃所有牌，由模式规则技能定义）

### （3）死亡后（death_after）

能发动：〖焚心①②③〗、〖功獒〗、〖裂围〗、〖破虏〗、〖孝德〗、〖征南〗、〖宗祚②〗；装备技能：〖飞龙夺凤②〗。

### 死亡结算结束后（death_end）

暂时没有作用。

## 死亡后的全局规则

◆ 其于之后的游戏中，**不再参与结算**。（〖悟心〗〖庸肆（SP）②〗计算 X 时已死亡角色不计入）

◆ **回合角色死亡的时机回退规则**（从示例看"其"均为当前回合角色）：

| 死亡位置 | 处理 |
|---|---|
| 回合内"回合结束前❶"**之前**的某一时机 a 的事件流程中死亡 | 先死亡流程 → 继续所有流程未结束的事件 → 回到 a → a 处理完毕**直接进入"回合结束前❶"**（跳过中间所有阶段与时机） |
| "回合结束前❶"**或之后**的某一时机 a 中死亡 | 先死亡流程 → 继续未结束的事件 → 回到 a → **正常**进行此回合的流程 |

> 裁定要点：〖乱武〗结算中贾诩死亡 → 乱武继续结算（于吉仍可〖蛊惑〗响应——仍在贾诩回合内）→ 结算结束 → 回合结束前❶（〖连破〗可发）；崔琰出牌阶段开始时死亡 → 死亡流程 → 回到"此阶段开始时" → 处理完直接回合结束前❶。
