# 牌状态改变事件（ChangeStateEvent）与明置事件

> 领域权威定义。来源：用户口述（2026-07-18）。实现参照 `shared/core/event/ChangeStateEvent.ts`（新，6 子类型自动检测）与旧项目 `event/types/event.state.ts`。
> 本事件涵盖**所有状态操作**（横置/重置/翻面/叠置/明置/暗置/移除/变更等）；**拼点牌被亮出**已移出本事件、归入 [pindian.md](pindian.md)。

## 牌状态改变的流程（除明置事件外）

### 时机序列

牌状态改变结算中：**牌状态改变前❶ → 牌状态改变前❷ → （改变状态）→ 牌状态改变后**；结算后：**牌状态改变结算结束后**。

| 时机 | 能发动 |
|---|---|
| 牌状态改变前❶ | 武将技能：〖结营②〗、〖谦节①〗；装备技能：〖明光铠②〗 |
| 牌状态改变前❷ | 武将技能：〖闺秀②〗 |
| （改变这些牌的状态） | — |
| 牌状态改变后 | 〖法恩①〗、〖法恩②〗、〖闺秀②〗的延时类效果、〖激词〗、〖解围②〗、〖敛财②〗、〖天辩②〗、〖鹰扬〗 |
| 牌状态改变结算结束后 | 暂时没有作用 |

## 明置事件（最复杂的状态改变）

按**明置原因**分四种流程：

### 1. 因发动暗置武将牌的**有消耗**触发类技能而明置

1. 在发动时机若满足条件（若有）**且能明置此武将牌** → 声明技能名，同时选择所有目标（若有），同时**确认执行消耗的所有细节**（如选定要弃置的牌，之后不能再改）
2. **明置此武将牌**
3. **势力确定**（见下"势力确定规则"）
4. **根据确认好的细节执行消耗**
   > 例：大乔（暗）-小乔（暗）发动〖天香〗，弃牌消耗执行时〖红颜〗**已生效**（明置在消耗之前）——弃置的手牌不能是受红颜影响的黑桃牌
5. 继续进行包括此技能的使用结算在内的当前所有已经开始的事件的流程

### 2. 因发动暗置武将牌的**无消耗且非奥秘技**触发类技能而明置

1. 满足条件且能明置 → 声明技能名 + 选择目标（若有）
2. 明置此武将牌
3. 势力确定（同 1-3）
4. 继续进行当前所有已经开始的事件的流程

### 3. 因**响应阵法召唤**而明置

1. 明置这些武将牌
2. **势力确定为此次阵法召唤的角色的势力**

### 4. **并非因发动技能或响应阵法召唤**而明置

1. 明置这些武将牌
2. 势力确定（同下规则）

### 势力确定规则（流程 1/2/4 共用）

- 若其于明置前**有势力**且已死亡的角色中有该势力的**君主** → 势力改为**野心家**
- 若其于明置前**没有势力**：
  - a. 若有为此武将牌上标识的势力的君主（存活）→ 势力为该势力
  - b. 若其他**已死亡**的角色中有该势力的君主 → 野心家
  - c. 均无君主时：该势力的其他角色数 + 已死亡的该势力角色数之和 **< X** → 该势力；**≥ X** → 野心家（X = 玩家数的一半）

### ◆ 不能明置的连锁限制

若一名角色**不能明置**一张武将牌，则其不能开始上述明置流程——除了不能明置外，也**不能发动此武将牌的触发类技能**、**不能通过明置此武将牌响应阵法召唤**。（不能明置的原因 = 受技能效果影响）

## "明置后"时机的延迟生成

**"明置后"（Open）不是在明置操作后立即生成的**：

| 场景 | 生成时点 |
|---|---|
| 直接在游戏流程时机产生的**非技能使用事件** | 在此事件流程结束之前（**处理区清理移动事件处理完毕后**），若有 n 名角色在此事件流程中明置过（从当前回合角色逆时针排序 A1…An），依次生成"A1 明置后"…"An 明置后"，处理完后此事件流程结束 |
| **技能使用事件** | 在此技能的**所有即时类效果执行完毕之前**（同样在处理区清理之后），同上依次生成，处理完后此技能使用事件流程结束 |

◆ 若 An **已死亡**，不生成"An 明置后"时机。

> 例：关羽-张飞使用【南蛮入侵】→ 甘夫人-孟获（暗）发〖祸首①〗明置、乐进-李典（暗）发〖忘隙〗明置 → 南蛮流程结束前：先插入处理区清理移动事件 → 生成"甘夫人-孟获明置后" → 处理完 → 生成"乐进-李典明置后" → 处理完 → 南蛮使用流程结束。

## 明置后（Open 时机内容）

**明置 1 张**时依次处理：

1. 能发动：〖闺秀①〗
2. 若此牌第一次被明置且另一张武将牌被明置过且两牌存在**珠联璧合**关系 → 获得 1 枚"珠联璧合"
3. 同上且两牌上有单独的阴阳鱼未组成完整阴阳鱼 → 获得 1 枚"阴阳鱼"
4. 若此次明置之前**所有角色均未明置过** → 获得 1 枚"先驱"
5. 若此牌是**主将**且姓名为曹操/刘备/孙权/张角 → 可替换为对应**君主武将牌**（正面朝上，原牌入武将牌堆）。然后将所有武将牌势力为魏/蜀/吴/群且当前势力为野心家的角色的势力**改回**对应势力。最后若**所有角色武将牌上标识的势力均相同** → 该势力所有角色（无论存活）**均获胜**

**明置 2 张**时：同上，条件改为"其中**至少一张**为第一次被明置"；君主替换看主将牌姓名。

> 凌天翼按：君主武将牌加入游戏从规则角度问题颇多（如张角替换可能导致体力上限变化），其价值更多体现在收藏上。

**明置结算结束后**：暂时没有作用。
