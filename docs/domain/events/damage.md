# 伤害事件（DamageEvent）

> 领域权威定义。来源：用户口述（2026-07-18）。实现参照 `shared/core/event/DamageEvent.ts`（新，已实现 + 6 项测试）与旧项目 `event/types/event.damage.ts`。

---

## 总则

◆ **伤害流程中的所有时机，均不会因来源已死亡、没有来源或受到伤害的角色已死亡而不生成**（时机的生成与谁能发动技能分离）。

首先根据角色造成或受到伤害的方式确定此伤害此时相应的**六要素**（用户裁定 R7，均已实现）：

| 要素 | 说明 | 实现 |
|---|---|---|
| 渠道 | 牌或技能（见 [event-resolution.md](../terms/event-resolution.md) 渠道） | 卡牌引用 + `skill` 属性 |
| 属性 | 普通/火焰/雷电 | `DamageType` |
| 来源 | 造成伤害的角色（可无） | source |
| 受伤角色 | 受到伤害的角色 | target |
| 伤害值 | 最终伤害值（基数+修正） | number |
| 是否为连环伤害 | 决定是否触发传导 | 连环标记 |

**造成/受到伤害的四种方式**（与 [event-resolution.md](../terms/event-resolution.md) 渠道四规则对应）：

1. 因执行牌或技能的效果
2. 因连环传导
3. 因转移"因执行牌或技能的效果而造成或受到的伤害"
4. 因转移"因连环传导而造成或受到的伤害"

## 时机序列

### 伤害结算开始前（damage_start）

能发动：〖刚直〗、〖绝情〗。

### （1）造成伤害时❶（damage_cause1）

能发动/执行：〖暗箭〗、〖从谏①〗、〖骄恣①〗、〖竭缘①〗、〖裸衣〗的延时类效果、〖倾袭〗、〖凶镬③〗、〖义绝〗的延时类效果、〖赠刀〗的延时类效果、〖忠义〗的延时类效果、〖助祭〗；装备技能：〖古锭刀〗、〖七宝刀②〗。

### （2）造成伤害时❷（damage_cause2）

能发动：〖豹变〗、〖穿心〗、〖潜袭（旧将）〗、〖无言①〗、〖制蛮〗；装备技能：〖寒冰剑〗、〖麒麟弓〗。

### （3）受到伤害时❶（damage_inflict1）

检测〖酒诗②〗的发动条件是否满足。

### （4）受到伤害时❷（damage_inflict2）

能发动：〖仇海〗、〖从谏②〗、〖公清②〗、〖骄矜〗、〖骄恣②〗、〖竭缘②〗、〖恪守〗、〖狂风〗的延时类效果、〖链祸〗、〖名士〗、〖天香（1v1）〗、〖耀武〗；装备技能：〖藤甲②〗。

### （5）受到伤害时❸（damage_inflict3）

能发动/执行：〖安东〗、〖白眉①〗、〖白眉②〗、〖大雾〗的延时类效果、〖公清①〗、〖怀橘②〗、〖贿生〗、〖宽释①〗的延时类效果、〖仁心〗、〖释衅〗、**〖天香〗**、〖隐士〗、〖远域〗、〖无言②〗；装备技能：〖白银狮子①〗、**〖护心镜〗**、〖烂银甲②〗、〖太平要术①〗。

◆ 在 {造成伤害时❶❷} / {受到伤害时❷❸} **尚未确定最终的伤害值**，因此此时发动的技能默认为**每造成/受到一次伤害能发动一次**（按事件计，非按点数计）。

### （扣减体力结算）

然后**来源即造成过此伤害，受到此伤害的角色即受到过此伤害**，进行**扣减体力结算**（嵌套 ReduceHpEvent，触发连环的重置也发生在扣减前，见 [general-operations.md](../terms/general-operations.md)）。

### （6）造成伤害后（damage_cause_after）

能发动：〖暴虐〗、〖点虎〗的延时类效果、〖夺锐〗、〖父魂②〗、〖虎啸〗、〖劫掠〗、〖军略〗、〖狂暴②〗、〖狂斧〗、〖狂骨〗、〖利驭〗、〖烈刃〗、〖魔军〗、〖谋逞〗、〖谋识〗的延时类效果、〖破军（旧将）〗、〖潜心〗、〖趫猛〗、〖忘隙〗、〖邀名〗、〖应势〗的延时类效果、〖征荣〗、〖雉盗〗、〖止啼②〗；装备技能：〖霹雳车①〗、〖三尖两刃刀〗。

### （7）受到伤害后（damage_inflict_after）

能发动：〖悲歌〗、〖贲育〗、〖布施①〗、〖布施②〗、〖仓储②〗、〖称好〗、〖称象〗、〖筹策〗、〖殚心〗、〖夺刀〗、〖恩怨②〗、〖反馈〗、〖放逐〗、〖附敌〗、〖刚烈〗、〖骨疽〗、〖归心〗、〖横江〗、〖恢拓〗、〖鸡肋〗、〖极略②〗、〖奸雄〗、〖节命〗、〖酒诗②〗、〖军略〗、〖狂暴②〗、〖魔躯②〗、〖破橹②〗、〖千幻①〗、〖权计①〗、〖燃殇①〗、〖忍戒〗、〖神躯②〗、〖审时②〗、〖矢北〗、〖恃勇〗、〖推锋①〗、〖忘隙〗、〖威虏〗、〖武魂①〗、〖先辅〗的延时类效果、〖孝廉①〗的延时类效果、〖新生〗、〖邀名〗、〖遗计〗、〖引兵②〗、〖拥嫡〗、〖御策〗、〖缘江烽火图③〗、〖止啼④〗、〖智迟〗、〖智愚〗、〖资粮〗。

**发动次数语义**："造成/受到伤害后"默认表示造成/受到**一次**伤害后——无论伤害值多少均为一次。**发动时机为"造成/受到 1 点伤害后"的技能能发动 X 次**（X = 此次伤害的伤害值）。

> 例：荀彧一次受到 2 点伤害 → 〖节命〗（"受到 1 点伤害后"措辞）可发动两次；曹丕一次受到 2 点伤害 → 〖放逐〗（"受到伤害后"措辞）只能发动一次。

### 伤害结算结束后（damage_end）

**能触发连环**（传导流程见 [general-operations.md](../terms/general-operations.md) 触发连环）。至此伤害流程结束。
