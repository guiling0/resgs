# R5 标准内容追齐 — 步骤拆分

> 所属 spec：[specs/r5-standard-content.md](../specs/r5-standard-content.md) · 计划：[plans/porting-map.md](../plans/porting-map.md)

| 编号 | 步骤 | 验证 |
|---|---|---|
| R5-01 | **标准牌全量**：108 张 + 军争牌实体数据核对与注册（花色/点数/种类对照旧 cards） | 牌数据与旧项目一致 |
| R5-02 | **军争牌使用逻辑**：酒/火杀/雷杀/火攻/铁索连环/古锭刀等 | 对局中可用且效果正确 |
| R5-03 | **标准武将第一批**：基础技能武将（摸牌/弃牌/加伤类等），技能学习旧实现后填充 | 技能可发动 |
| R5-04 | **标准武将第二批**：判定/转化/延时类技能武将 | 技能可发动 |
| R5-05 | **拼点机制**：PindianEvent（合法目标/逐对拼点/赢与未赢） | 对局可复现 |
| R5-06 | **明置/势力/珠联璧合**：ChangeStateEvent 全档 + 君主技 | 对局可复现 |
| R5-07 | **连环传导**：横置/重置 + 属性伤害传导 | 对局可复现 |
| R5-08 | **翻面/叠置**：跳过回合实现 | 对局可复现 |
| R5-09 | **客户端监听配套**：拼点结果/明置动画/连环标记/翻面显示 | 消息流可见且监听生效 |
| R5-10 | **R5 验收**：14 档事件全落地 + 全部标准武将可复现 + 无挂死 | M2 里程碑（与 R6 共同达成） |
