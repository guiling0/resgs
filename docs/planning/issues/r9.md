# R9 客户端体验追齐 — 步骤拆分

> 所属 spec：[specs/r9-client-experience.md](../specs/r9-client-experience.md) · 计划：[plans/porting-map.md](../plans/porting-map.md)

| 编号 | 步骤 | 验证 |
|---|---|---|
| R9-01 | **大厅模块**：房间列表/创建/加入/玩家信息（对照 clientv0 UILobby/UILobbyItem） | 大厅功能可用 |
| R9-02 | **房间模块**：座位/准备/开始/房主管理/聊天入口（对照 UIRoom/UISeat） | 房间功能可用 |
| R9-03 | **游戏桌完整化**：座位布局/手牌装备判定区/技能按钮/武将头像体力/标记/状态图标（对照 UIGameRoom/UISelfSeat/UISkillButton/UITextMark 等） | 游戏桌完整 |
| R9-04 | **选择与弹窗**：目标/弃牌/给牌/技能发动/确认（对照 UIChooseCards/UIItems/UIOptionButton/UIDialog 等） | 弹窗交互正确 |
| R9-05 | **聊天模块**：公屏/私聊/表情（对照 UIChat） | 聊天可用 |
| R9-06 | **录像模块**：保存与回放（对照 Replay/UIVideo） | 录像可回放完整一局 |
| R9-07 | **音效模块**：技能语音/音效/背景音乐（对照 UISkillAudio/Resources） | 关键节点触发 |
| R9-08 | **皮肤动画**：武将特效迁移（对照 UISkinAnimation/effects/） | 动画触发正确 |
| R9-09 | **设置/关于**：UIAbout/UIAboutCard 等 | 可用 |
| R9-10 | **R9 验收**：clientv0 功能清单逐项勾选 + 8 人对局流畅 | 进入 R10 |
