# R10 服务端追齐 — 步骤拆分

> 所属 spec：[specs/r10-server-completion.md](../specs/r10-server-completion.md) · 计划：[plans/porting-map.md](../plans/porting-map.md)

| 编号 | 步骤 | 验证 |
|---|---|---|
| R10-01 | **用户系统**：注册/登录/JWT（对照 middleware/auth、UserManager、routes） | 认证流程可用 |
| R10-02 | **DB 模型**：MongoDB User/MatchState（对照 db/models/） | 模型可用 |
| R10-03 | **Colyseus 房间完整化**：LobbyRoom（列表/创建/加入/聊天）+ GameRoom（join/seat/ready/start/chat/托管/投降） | 房间流程完整 |
| R10-04 | **联机纯消息传输**：Colyseus 通道转发 Envelope（send('game', payload)），状态不 schema 同步 | 两台浏览器状态一致 |
| R10-05 | **录像存储与回放接口**：事件序列落库（MatchState）+ 回放数据接口 | 可回放完整一局 |
| R10-06 | **断线重连**：重连收快照 + 待处理询问恢复 | 重连后对局可继续 |
| R10-07 | **托管/投降** | 可用 |
| R10-08 | **管理接口**：admin 路由（用户/房间） | 可查询 |
| R10-09 | **R10 验收**：联机端到端一局 + 断线重连 + 录像回放 | M4 里程碑达成，全量追齐完成 |
