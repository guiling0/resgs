# R7 模式扩展（1v1 / 3v3）

> 所属计划：[plans/porting-map.md](../plans/porting-map.md) · 步骤拆分：[issues/r7.md](../issues/r7.md)

## 需求

重写 old/resgsv1 的 **1v1、3v3** 两个模式扩展（新 API），含模式规则、专属武将包与行为实现。

1. **1v1 模式**（旧 `extensions/1v1/`）：单挑规则（胜负/体力/奖惩）、专属武将包（1v1 武将）、选将流程
2. **3v3 模式**（旧 `extensions/3v3/`）：冷/热阵营、主帅/前锋选将、奖惩规则、胜负判定
3. **ModeBuilder 完善**：`beforeStart/mainProcess/settings/rules` 支撑模式定制
4. **武将行为**：两模式专属武将（R6 壳子 + 技能学习实现）
5. **协议与客户端**：模式相关消息（选将/阵营显示/胜负）与监听

## 目标

- 1v1、3v3 各可完整对局（人类 vs AI），规则与旧项目一致

## 前置依赖

- R5（标准内容：基础机制全档）+ R6（数据管线：专属武将壳子）

## 验收标准

1. 1v1 一局可玩：选将→对局→胜负正确；奖惩规则符合旧实现
2. 3v3 一局可玩：冷热阵营分配正确、主帅/前锋选将流程正确、胜负判定正确
3. 模式武将技能生效（对局中可触发，日志证据）
4. 模式切换：sgs.modes 同时存在 default/1v1/3v3，Room 可按模式启动

## 产出物

- `extension/` 下 1v1、3v3 扩展包（mode + 武将 + 技能）
- `shared/core/room/builder/ModeBuilder.md` 能力补齐（或直接按代码实现）
- 协议消息与客户端监听
