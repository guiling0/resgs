## 角色判定的流程

判定结算中有**五个时机**：判定时 → 成为判定牌后 → 判定结果确定前 → 判定结果确定后❶ → 判定结果确定后❷。

### （1）判定时（judge）

**确定判定牌**：进行判定的角色**亮出牌堆顶的一张牌**，称为"其判定牌"（亮出 = 置入处理区，见 [card-operations.md](../terms/card-operations.md)）。

能执行的效果：〖咒缚〗的延时类效果。

### （2）成为判定牌后（judge_card）

暂时没有作用。

### （3）判定结果确定前

能发动的武将技能：〖缓释①〗、〖缓释②〗、〖鬼才〗、〖鬼道〗、〖极略①〗、〖米道〗、〖贞烈（旧将）〗。

然后**确定此次判定的结果**——**生效后的判定牌的花色、点数、名称等信息**称为此次判定的"结果"。

> 实现注（用户裁定）：实现中使用**虚拟牌数据**作为判定结果，因为后续会有**只修改判定结果**（不换判定牌）的技能。

### （4）判定结果确定后❶（judge_result_after1）

能执行的效果：〖洛神〗的延时类效果、〖双雄〗的延时类效果、〖屯田①〗的延时类效果、〖助祭〗的延时类效果。

### （5）判定结果确定后❷（judge_result_after2）

能发动：〖颂威〗、〖天妒〗、〖筑围〗。

### 判定结算结束后（judge_end）

暂时没有作用。至此判定流程结束。
