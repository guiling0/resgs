# 身份模式：开始前流程

> 领域权威定义。来源：用户口述（2026-07-18）。
> 实现：旧项目由 ReadyEvent 加各时机 + 模式规则技能；**新项目由模式（GameMode）的 `beforeStart` 函数按顺序处理**。

---

## 1. 游戏目标

玩家的游戏目标由其获得的身份牌决定：

| 身份 | 目标 |
|---|---|
| 主公 | 消灭所有的反贼和内奸，平定天下 |
| 忠臣 | 不惜一切保护主公，胜利条件与主公相同 |
| 反贼 | 杀死主公，推翻统治 |
| 内奸 | 消灭除自己外所有的人，成为最后的存活者 |

**游戏结束条件与获胜判断**：

1. 死亡的角色身份为**主公**：若仅有一名角色存活且其身份为内奸 → 该角色获胜；否则所有身份为反贼（**无论是否存活**）的角色均获胜
2. 死亡的角色身份不为主公：若所有反贼和内奸均已死亡 → 主公和所有忠臣（**无论是否存活**）均获胜

> 实现：游戏结束条件与获胜判断作为**规则技能**加入模式专属技能。

## 2. 分发身份牌并分配座次序号

主公身份牌**正面朝上**置于面前，其他玩家身份牌**扣置**于各自面前。主公座次序号为 **1**，其他角色从主公开始按**逆时针**从小到大依次分配座次序号。

> 实现：身份牌放置方式 = `PlayerState.rolePut`。

## 3. 选择武将牌

1. 主公玩家：从所有**主公武将牌**中随机获得三张 + 从剩余所有武将中随机获得两张 → 从这五张中选一张**正面朝上**竖放于身份牌右侧。若选择的是**神或西势力**武将牌 → 将其角色的势力改为魏/蜀/吴/群中的一种
2. 其余每名玩家：随机获得三张武将牌 → 各选一张**（暗置选择）** → 所有玩家**同时亮出** → 获得神/西势力武将牌的玩家改势力为魏/蜀/吴/群之一

## 4. 选择体力牌

- 玩家数 **> 4**：主公的体力牌勾玉数 = 其武将牌勾玉数 **+1**；其他玩家 = 各自武将牌勾玉数
- 玩家数 **≤ 4**：所有玩家 = 各自武将牌勾玉数

均露出所有不空心的勾玉。

## 5. 分发起始手牌

形成牌堆，每名玩家获得牌堆顶的**四张**牌作为起始手牌。

◆ 角色于**游戏开始之前**得到牌前/后，**不能发动**发动时机为"移至目标区域前/后"的技能。（例：夏侯惇在得到起始手牌后❷不能发动〖清俭①〗）

## 6. 进行游戏

由身份为主公的角色开始，逆时针以回合方式依次进行（见 [turn.md](turn.md)）。

---

> 注（技能清单的性质）：各事件文档时机下列出的技能，是基于所有规则**穷举**出的可发动技能——旧项目不一定有实现。它们是移植提示；**每个技能实现完成后，须根据时机同步到对应事件文档的对应时机下**。
