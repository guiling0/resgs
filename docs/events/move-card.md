# 移动事件（MoveCardEvent）

> 领域权威定义。来源：用户口述（2026-07-18）。实现参照 `shared/core/event/MoveCardEvent.ts`（新，已实现+18 项测试）与旧项目 `event/types/event.move.ts`。

---

## 触发条件与处理区自动清理

因一种操作而改变牌所在的区域，须进行**移动结算**。

**处理区自动清理**（默认插入的移动事件 C）：

| 场景 | 清理时点 |
|---|---|
| **非技能使用事件** A 中插入"将牌移至处理区"的移动事件 B | 在**事件 A 的流程结束之前**，系统将处理区里**因事件 B 而移至处理区**的所有牌置入弃牌堆（称为**因事件 A 而移至弃牌堆**），然后 A 流程结束 |
| **技能使用事件** A 中插入移动事件 B | 在此技能的**所有即时类效果执行完毕之前**，同上清理，然后 A 流程结束 |

## 移动和失去牌的原因（reason）

导致移动结算的操作即为此移动结算中移动和失去牌的**原因**：

1. **使用**：使用牌时将对应实体牌（其中属于该角色的）置入处理区 = 因使用而移动和失去（例：陆逊使用【八卦阵】→ 实体牌入处理区后❷〖连营〗→ 入装备区同时【白银狮子】入弃牌堆后❷执行〖白银狮子②〗）
2. **打出**：对应实体牌置入处理区
3. **重铸/合纵（连横）**：置入弃牌堆/手牌区（连横即合纵的旧称，中途更名，国战专有机制，见 [card-operations.md](../terms/card-operations.md) 合纵）
4. **弃置**：A 弃置或 B 弃置 A 的牌 → **A** 因弃置而移动和失去
5. **交给**：A 交给 B，B 获得 = A 因交给而移动和失去
6. **拼点**：同时各将一张手牌扣置入处理区（例：〖陷阵〗拼点牌入处理区后❷张春华可发〖伤逝〗）
7. **交换**：双方同时置入处理区 = 同时因交换而移动和失去（例：〖缔盟①〗中双方失去手牌后❷逆时针依次响应〖伤逝〗〖连营〗）
8. **获得**：A 获得 B 的手牌/装备区里的牌 = B 因 A 的获得而移动和失去
9. 其他（例：〖攻心〗置于牌堆顶 = 失去）

◆ **移动的目标区域或被移动的牌的改变，不会令导致此次移动的操作或执行此操作的角色改变**。（例：〖仁德〗交给的牌被〖章武②〗改置牌堆底，仍计入刘备"以〖仁德〗交给其他角色的手牌数"）

## 移动一张牌的流程（五时机）

### （1）确定移动的牌时（movecard_fixed）

能发动：〖挽危〗。此时此次移动的牌已确定。

### （2）移至目标区域前❶（movecard_before1）

此牌在**原区域**里。**别名规则**：

- 原区域为 B 的手牌/装备区 → 亦即"B **失去此手牌/装备区里的牌**前❶"
- 原区域为 B 的手/装区且目标区域为除 B 手/装区外的区域 → 亦即"B **失去此牌**前❶"
- 目标区域为 B 的手牌区 → 亦即"B **得到此牌**前❶"

能发动的装备技能：〖木牛流马③〗、〖霹雳车②〗。

### （3）移至目标区域前❷（movecard_before2）

此牌在原区域里，别名规则同上（❷ 版）。能发动：〖空城②〗、〖奇才②〗、〖千幻③〗、〖谦逊（国）②〗、〖帷幕②〗、〖章武②〗；装备技能：〖白银狮子②〗、〖太平要术③〗。

**Before2 之后、执行移动前的固定规则**（依序）：

1. 红桃/黑桃【浮雷】且目标区域不为处理区或判定区 → 所有角色各弃其所有"霹"/"雳"
2. 【敕令】非因使用而移动且目标为弃牌堆 → 系统将目标区域**改为府库**
3. **衍生牌**目标为弃牌堆 → 此牌**消失**
4. 按此牌在原区域的正/背面朝上状态移动，到达后按目标区域**默认放置方式**放置（例：〖活墨〗置于牌堆顶的牌正面朝上移动、背面朝上放置）
5. **虚拟牌对应关系**（四分支）：
   | 场景 | 虚拟牌 | 对应关系 |
   |---|---|---|
   | 非延时锦囊虚拟牌的实体牌，因技能效果从使用/打出流程规定的应在区域移走 | **不消失** | **切断**（虚拟牌不再有实体牌） |
   | 延时锦囊实体牌从判定区移至非判定区/处理区 | **消失** | 切断 |
   | 延时锦囊实体牌从处理区移至判定区 | 不消失 | 不切断，但虚拟牌**花色/点数改为实体牌的** |
   | 延时锦囊实体牌从判定区移至判定区 | 同上 | 同上 |

   > 裁定要点：〖章武②〗把【杀】的实体牌之一改置牌堆底 → 此【杀】与全部实体牌的对应关系**中断** → 〖奸雄〗（无牌可获得）与〖勇决〗（无对应实体牌）都不能发动；【闪电】判定中被〖涅槃〗弃置判定区其他延时锦囊 → 互不干扰，闪电流程继续
6. 将目标区域设定为此牌的**维系区域**

### （4）移至目标区域后❶（movecard_after1）

此牌在**目标区域**里，别名规则同上（后❶ 版）。能执行：〖六龙骖驾③〗、〖木牛流马③〗的延时类效果、〖霹雳车②〗的延时类效果。

### （5）移至目标区域后❷（movecard_after2）

别名规则同上（后❷ 版）。能发动/执行：〖兵略〗、〖恩怨①〗、〖弘德〗、〖集军〗的延时类效果、〖礼让〗、〖连营〗、〖良姻〗、〖落英①〗、〖落英②〗、〖明哲②〗、〖纳蛮①〗、〖纳蛮②〗、〖祈禳〗、〖趫猛〗的延时类效果、〖勤国②〗、〖清俭〗、〖忍戒〗、〖散文〗、〖伤逝〗、〖慎断〗、〖甚贤〗、〖守成〗、〖死谏〗、〖屯田①〗、〖黠慧②〗、〖枭姬〗、〖旋风②〗、〖旋略〗、〖逊贤②〗、〖涯角〗、〖燕语〗的延时类效果、〖义舍②〗、〖姻礼〗、〖展骥〗、〖章武①〗、〖自书②〗、〖纵玄〗、〖总御①〗；装备技能：〖白银狮子②〗的延时类效果、〖太平要术③〗的延时类效果、〖银月枪〗。

◆ **可操作性约束**：技能有操作此牌的效果时，须**此牌仍在目标区域里且移入后至轮到其发动前未移动过**才能发动。（例：〖落英②〗先获得弃牌堆里的牌 → 后轮到的〖趫猛〗不能再获得；牌被再次移动同理）

**After2 之后的固定规则**：

- 此牌在原区域里为【金蝉脱壳】且原区域为手牌区且目标为弃牌堆且因弃置 → 其摸一张牌
- 若**原区域为弃牌堆** → **清除此牌之前的所有游戏流程相关的信息**（例：弃牌堆的牌经洗牌回到牌堆再被摸到，不再是"曾于此阶段弃置过的牌"→〖固政〗失效）

### 移动结算结束后（movecard_end）

暂时没有作用。至此移动流程结束。

## 同时移动多张牌（差异点）

- 各牌**分别**在各自的原区域/目标区域；别名规则按"其中有部分牌……"生效
- 固定规则逐牌应用（浮雷/敕令/衍生牌消失）
- 正面朝上的牌正面朝上移、背面朝上的牌背面朝上移，同时进行
- ◆ 将多张牌置于牌堆顶/底时，**放置顺序由移动者决定**
- 多目标使用牌：目标之一获得此牌全部实体牌（〖奸雄〗〖反馈〗〖刚烈〗杀死使用者等）→ 虚拟牌**依然存在**，须继续对其余目标结算
- After2 可操作性约束（部分牌版）：只能操作**仍在目标区域且未移动过**的那部分牌（例：〖落英②〗先拿走梅花 → 〖燕语〗只能对剩余黑桃执行两次）
- 【金蝉脱壳】多角色版：以此法失去者**各**摸一张牌

## 牌面信息基准

◆ 此次被移动（过）的一张牌的牌面信息**默认指此牌在原区域里的牌面信息**。（例：高顺弃置受〖禁酒〗影响视为【杀】的【酒】→ 按原区域信息此牌是【杀】→ 〖决死〗判定"弃置了【杀】"成立，庞德不执行使用【决斗】的效果）
