# 牌的使用事件（UseCardEvent）

> 领域权威定义。来源：用户口述（2026-07-18）。参考旧项目 `event/types/event.use.ts`（UseCardEvent / UseCardToCardEvent / UseCardSpecialEvent 三个类）。
> ⚠️ **用户设计决策**：旧项目分三个子类（UseCardEvent / UseCardToCardEvent / UseCardSpecialEvent）分别处理基本牌/延时锦囊/装备的流程差异。**新项目统一使用一个 UseCardEvent**，在时机构建时按牌类型动态生成不同的时机序列。

---

## 总则

开始触发一张牌的使用事件 → 使用者即**使用过此牌**（计入使用计数，不论牌种类）。

◆ **使用流程中的所有时机均不会因使用者已死亡而不生成**。（〖无谋〗例：吕布使用【决斗】时发动→失去1点体力死亡→后续指定目标时〖佐定〗仍可发动）

### 使用计数

使用者的视角下：虚拟牌一旦进入使用流程即计为"使用过此牌"（〖疠火①〗后改种类不影响计数，例：程普使用【杀】计 1 次，疠火改火杀不增加计数；〖八卦阵〗使用无对应实体牌的闪也计 1 次→共使用 2 牌）

---

## 前置：实体牌入处理区

首先将其对应的实体牌置入处理区，然后开始使用预结算。

---

## 第一部分：使用预结算（Before Use Settlement）

**使用结算前**包含 8 类时机，注意这是**动态时机结构**（时机数量不固定、随目标数变化）。核心规则：

- ◆ 目标列表中没有目标 → **终止此使用流程**
- ◆ 目标数在插入结算中减为 0 → 插入结算完毕 → **终止此使用流程**

### 时机生成顺序（正常情况，以 n 个目标为例）

声明使用牌后 → 选择目标后 → 牌被使用时 → （逐个：指定 T1 时 → … → 指定 Tn 时）→ （逐个：成为 T1 时 → … → 成为 Tn 时）→ （逐个：指定 T1 后 → … → 指定 Tn 后）→ （逐个：成为 T1 后 → … → 成为 Tn 后）→ 使用结算准备工作结束时

### 各时机技能清单

**（1）声明使用牌后**（`usecard_declare_after`）：〖疠火①〗、〖朱雀羽扇〗

**（2）选择目标后**（`usecard_assign_target_after`，按口述实际在选择目标后、牌被使用前）：〖奔袭③〗、〖蚕食②〗、〖短兵〗、〖福绵①〗延时、〖击虚〗延时、〖疠火②〗、〖乱战②〗、〖巧说〗延时、〖神戟〗、〖神戟②〗、〖誓仇〗、〖方天画戟（国）〗
◆ 此时机发动技能**不能令与目标列表中已有对应关系的角色也成为此牌的目标**（只能额外加人，不能把已有目标的人再重复加为目标）

**（3）牌被使用时**（`usecard_used`）：〖奔袭①〗、〖残蚀〗延时、〖冲阵①②〗、〖奋音〗、〖抚蛮〗延时、〖复难〗、〖伏骑〗、〖观潮〗延时、〖悍勇〗、〖蒺藜〗、〖极略③〗、〖集智〗、〖渐营〗、〖狂才〗延时、〖雷击〗、〖龙胆（阵）①②〗延时、〖龙吟〗、〖明哲①〗、〖咆哮（国）②〗〖咆哮（阵）②〗、〖辟撰①〗、〖强识〗延时、〖攘夷〗延时、〖仁望〗、〖设伏②〗、〖司敌①②〗、〖往烈②〗、〖问计〗延时、〖无谋〗、〖武娘〗、〖兴棹②③〗、〖影兵〗、〖总御②〗、〖青龙偃月刀（国）〗
**此时须对目标列表中的所有目标重新排序**（因选择目标后可能已有增减）

**（4）（连续若干个）指定目标时**（`usecard_assign_target`）：〖谏征〗、〖救援〗、〖替巾〗、〖谮毁〗。此时须对目标列表重新排序。

**（5）（连续若干个）成为目标时**（`usecard_become_target`）：〖蚕食①〗、〖寄篱〗、〖空城①〗、〖流离〗、〖千幻②〗、〖谦逊（国）①〗、〖求援〗、〖舍宴〗、〖帷幕①〗、〖孝廉①〗、〖镇卫〗、〖明光铠①〗
**此时其即对目标列表中的所有目标对应的角色使用过此牌**（"对XX使用过此牌"的判定由此定型；马岱杀曹冲被镇卫取消→未对曹冲使用过此牌→〖窃听〗可发动；马岱闪电→文聘令转移→马岱**对文聘**使用过此闪电→〖窃听〗不可发）

**（6）（连续若干个）指定目标后**（`usecard_assign_target_after`）：〖逞功〗、〖芳魂①〗、〖奋威〗、〖凤魄〗、〖锋矢〗、〖奉迎〗延时、〖祸首②〗、〖激昂①〗、〖鞬出〗、〖集军〗、〖拒战②〗、〖联翩①②〗、〖烈弓〗、〖烈弓②〗、〖烈弓（阵）①〗、〖乱战③〗、〖谋溃〗、〖鸟翔〗、〖咆哮（阵）③〗、〖破军〗、〖奇制〗、〖肉林①〗、〖讨袭〗、〖铁骑〗、〖铁骑（阵）〗、〖图射〗、〖无双①②〗、〖战意〗延时、〖征服〗、〖专对①〗、〖佐定〗 + 〖雌雄双股剑〗、〖飞龙夺凤①〗、〖七宝刀①〗、〖青釭剑〗、〖青龙偃月刀〗、〖衠钢槊〗

**（7）（连续若干个）成为目标后**（`usecard_become_target_after`）：〖从谏〗、〖啖酪〗、〖父荫〗、〖激昂②〗、〖荐降〗、〖拒战①〗、〖慷忾〗、〖辟撰②〗、〖谦雅〗、〖肉林②〗、〖恃才②〗、〖守玺〗、〖天命①②〗、〖婉容〗、〖无双③〗、〖享乐〗、〖协穆〗延时、〖疑城〗、〖义襄〗、〖庸肆（国）②〗、〖贞烈〗、〖镇南〗、〖专对②〗 + 可使用【金蝉脱壳】

◆ 若此牌为**【闪】/【金蝉脱壳】/【无懈可击】**：上述（1）~（7）的所有技能/效果**均不能发动/执行**。（此为 UseCardToCardEvent 的语义——旧项目用子类刨除时机，新项目统一 UseCardEvent 时在时机构建中按牌类型剔除）

**（8）使用结算准备工作结束时**（`usecard_ready`）：【五谷丰登】的执行动作。

### 使用预结算的收尾处理

**装备牌**：将对应实体牌置入对应装备子区（子区有牌 → 同时开始移动旧牌入弃牌堆）；**延时锦囊牌**：实体牌置入目标对应角色的判定区。

至此使用预结算结束。将**对应的角色已死亡的所有目标移出目标列表** → 对目标列表重新排序 → 形成**最终目标列表**。

然后：
- **延时锦囊**：有目标 → 使用流程结束（虚拟牌不消失、对应关系保留——进入特殊使用流程）；无目标 → 使用流程结束（虚拟牌消失、对应关系切断）
- **装备**：使用流程结束（虚拟牌消失、对应关系切断）
- **基本牌/普通锦囊**：继续进行后续使用流程

## 第二部分：使用结算（Use Settlement）

使用结算中有：**对当前目标使用结算开始时 → 对当前目标生效前 → 对当前目标生效时 → 对当前目标生效后**。

使用结算须从目标列表中的**第一个**目标开始，所有目标**依次作为"当前目标"**进行一次**循环点 A→…→循环点 B** 的流程。

### （循环点 A）

若此牌**对当前目标无效** → 不生成"对当前目标使用结算开始时"。循环点 A 之前能令牌对当前目标无效的技能：〖啖酪〗、〖方天画戟（国）〗、〖奋威〗、〖守玺〗、〖享乐〗、〖贞烈〗、〖征服〗、〖专对②〗。

### （1）对当前目标使用结算开始时（`usecard_effect_start`）

能发动/执行：〖祸首①〗、〖巨象①〗、〖蛮裔②〗、〖无言（旧将）①②〗、〖毅重〗、〖智迟〗延时、〖仁王盾〗、〖藤甲①〗

然后若此牌对当前目标**无效** → 不生成后续三个生效时机。

> 此时是**第一次**判断无效（影响技能仅上述罗列的），与循环点 A 的第二次判断分开。

### （2）对当前目标生效前（`usecard_effect_before`）——响应窗口

能进行响应：使用【闪】、普【无懈可击】、国【无懈可击】。

**无双/肉林/鸟翔类效果**：将抵消此杀的方式改为依次使用**两张闪**——第一张闪使用流程结束→生效前结束→生成**第二个"生效前"**→第二次正常判定。

响应后：
- 此牌**被抵消** → 生成"**被抵消后**"（`usecard_offset`）：〖龙胆③〗、〖龙胆（阵）③〗、〖猛进〗、〖谋溃〗延时、〖方天画戟（国）〗延时、〖贯石斧〗、〖青龙偃月刀（旧）〗 → **使用结算结束**
- 此牌**未被抵消** → 生成"对当前目标生效时"

### （3）对当前目标生效时（`usecard_effect`）：能发动：〖谦逊①〗、〖谦逊②〗

### （4）对当前目标生效后（`usecard_effect_after`）：执行此牌的牌面"作用效果"

◆ 装备牌的效果 = 令角色于失去此装备之前**拥有此装备技能**（"使用装备牌"和"使用装备技能"是两个概念）。

### （循环点 B）

返回循环点 A，下一个目标作为"当前目标"。

## 第三部分：使用结算结束后（Post-Use Settlement）

### （1）使用结算结束后❶（`usecard_end1`）

能发动：〖勤国①〗；牌执行动作：【五谷丰登】、【调虎离山】

### （2）使用结算结束后❷（`usecard_end2`）

能发动/执行：〖反攻〗、〖救援〗延时、〖疠火①〗延时、〖立军〗、〖替巾〗延时、〖替身〗延时、〖亦算〗、〖勇略〗延时、〖忠勇〗

### （3）使用结算结束后❸（`usecard_end3`）

能发动/执行：〖巨象②〗、〖乱击〗延时、〖恃才①〗、〖伺盗〗、〖兴乱〗、〖逊贤①〗、〖应援〗、〖勇决〗、〖贞良②〗、〖止息②〗

至此使用流程结束，此**虚拟牌消失**且**中断此虚拟牌与此实体牌之间唯一的对应关系**。

## 附：目标动态增减与重新排序规则

- 目标插入（〖誓仇〗→也成为/大乔〖流离〗→转移）后须对所有未生成过当前步骤时机的目标**按逆时针重新排序**
- 成为目标时对某目标"使用过此牌"的判定仅在该目标的此时机定型，后续取消/死亡不影响
- ◆ 目标列表里的目标**是否为合法目标不影响此牌的使用流程**（〖雌雄双股剑〗对空城诸葛亮生效例）

**死者相关差异**：

| 牌类型 | 目标对应的角色死亡 | 结果 |
|---|---|---|
| 延时锦囊 | 在使用流程中死亡（从 assign→effect_after 任一环节） | 移出目标列表 → 技能/牌使用流程结束 → **终止此牌使用流程** |
| 基本牌/普通锦囊 | 同上 | **不移出目标列表**，此后与 Tm 有关的时机照常生成（是否生成与其是否死亡无关） → 技能/牌使用流程结束 → **终止当前时机**（非终止使用流程——只断当前时机，后续时机继续） |

> 注：使用流程的收尾：所有目标结算完毕后，**虚拟牌消失 + 对应关系切断**（基本牌/普通锦囊）。装备牌和延时锦囊的使用预结算结束后即处理对应实体牌，不计入循环 A↔B 的主使用结算。

## 实现映射（新项目统一 UseCardEvent 设计）

| 规则 | 旧项目 | 新项目 |
|---|---|---|
| 基本牌/锦囊（正常流程） | UseCardEvent | 统一 UseCardEvent，时机构建含全部 15 个时机 |
| 延时锦囊（特殊使用流程） | UseCardSpecialEvent（子类，刨除时机） | 统一——时机构建按牌类型**跳过预结算收尾后到循环 AB 的全部时机** |
| 对牌/对自己的牌（闪/无懈/金蝉） | UseCardToCardEvent（子类，刨除 1-7 时机） | 统一——时机构建按牌类型**剔除声明后~成为后时机段** |
| 装备 | UseCardSpecialEvent | 统一——预结算收尾执行装备区替换 + 虚拟牌消失 |
| 动态时机生成 | 逐个目标 assign/become/assign_after/become_after | 目标列表的逆时针编号 + 重排序 + 未生成过时机检测 |
| `transfer`/`cancelCurrent`/`becomeTarget` | targetList 方法 | 保持 targetList 的完整操作集（取消=移出+终止时机；转移=移出+新插入+重排序） |
| 15 个时机 | UseCardDeclare~/ChooseTarget~(~用 choose_target)/Used/AssignTarget/BecomeTarget/AssignTargetAfter/BecomeTargetAfter/Ready/EffectStart/EffectBefore/Offset/Effect/EffectAfter/End1/2/3 | 全部对应 ✅（注：choose_target 枚举不叫"选择目标时"而叫"使用选择目标时"，需核对） |

### 设计要点

1. **统一 UseCardEvent**：在 `buildTriggers()` 中按 `card.type` 分支构建时机序列，替代旧项目的三个子类
2. **目标列表的动态性**：assign→become→assign_after→become_after 四段的逐个目标展开 + 每段过后重排序 + "未生成过此步骤时机"检测
3. **"循环点 A→B"** = UseCard 的 `主要结算区`——从第一目标逐目标过 `effect_start → effect_before → [offset] → effect → effect_after`
4. **对闪/无懈/金蝉的时机剔除**：此三种没有 assign/become 序列——它们的目标是牌本身，不是角色
5. **对延时锦囊/装备的收尾**：预结算结束 → 实体牌移动 → 使用流程结束（不进入循环 A/B）
