# 拼点事件（PindianEvent）

> 领域权威定义。来源：用户口述（2026-07-18）。参考旧项目 `event/types/event.pindian.ts`。

---

## 定义

角色拼点（流程）：

### （1）进行拼点时

拼点的**发起者**选择拼点的**合法目标**（从当前回合角色开始按逆时针方向编号 T1、T2……Tn）。

◆ 拼点的合法目标 = **有手牌的其他角色**。若未说明能选择的目标的数量，默认目标数上限为 **1**。

◆ **没有手牌的角色不能发起拼点**。

然后：发起者和所有目标**同时**→ 各自从手牌区选择一张此次拼点的牌 → **扣置入处理区**（维系区域 = 处理区）→ **亮出** → 按 T1→Tn 顺序确定每对拼点结果并生成对应的"拼点结果确定后"时机。

**确定拼点结果的方法**：若两张牌点数不同 → 点数大者**赢**、小者**未赢**；点数相同 → 两者**均未赢**。

> 注（与多名角色拼点时）：发起者用**同一张牌**和每个目标各拼一次。

### （2）拼点结果确定后

能发动的武将技能：〖锋略〗、〖鼓舌〗的延时类效果、〖伪·鼓舌〗的延时类效果、〖止啼③〗、〖纵适〗。

### 拼点结算结束后

暂时没有作用。

## 时机序列

| 序号 | 时机 | TimingName |
|---|---|---|
| 1 | 进行拼点时（Pindian） | `pindian` |
| 2 | 拼点牌被亮出时 | `pindian_card_show` |
| 3 | 反复：发起者 vs T1/T2/…/Tn 拼点结果确定后 | `pindian_result` |
| 4 | 拼点结算结束后 | `pindian_end` |

## 实现映射

| 内容 | 旧项目 | 新项目 |

| 参与者选牌 | `doRequestAll` 并行询问所有参与者 | M4 通过 ChooseManager 实现 |
| 扣置入处理区 | `room.moveCards`（MoveCardEvent） | MoveCardEvent ✅（reason='pindian'） |
| 多目标用同一张牌 | `cards: Map<Player, GameCard>` 发起者固定一张 | 新项目同样逻辑 |
| 赢/未赢判定 | 点数比较（旧代码无此段，在 trigger 回调中判定） | M4 实现 |
| 拼点牌维系区域 = 处理区 | — | 命名牌应基于卡牌标记实现，移动即失效 |
