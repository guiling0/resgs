# 视为

注：在OL上还有一种描述中出现了“视为”，例如〖神速〗的“视为使用【杀】”。这种情况在规则集中称为“使用无对应的实体牌的【杀】”，这样的描述能更好地显示虚拟牌与实体牌的对应关系。虚拟牌与实体牌的对应是规则的基石之一，即结算实际上是针对虚拟牌的信息进行的，被使用或打出的必然是虚拟牌，通常情况下虚拟牌会有对应的实体牌，而有的虚拟牌没有对应的实体牌。详见第四章使用事件的说明。

1、一名角色视为装备着装备牌即其拥有此装备牌的防具技能但其装备区里没有装备牌。

```
马超发动〖铁骑〗令装备区里没有防具牌的诸葛亮的带有“锁定技“标签的武将技能于当前回合内无效，诸葛亮受到〖八阵〗影响拥有的防具技能〖八卦阵〗不会受到〖铁骑〗的影响。
```

```
装备【青釭剑】的角色对装备区里没有防具牌的诸葛亮（火）使用【杀】，诸葛亮不能发动〖八卦阵〗进行响应。
```

```
未受伤的吴国太能对装备区里只有一张牌的黄月英和装备区里只有一张牌的诸葛亮（火）发动〖甘露〗。
```

2、<信息为A的事物>视为<信息为B的事物>，即该事物的该信息以B为准。

```
刘禅在成为关羽（神）使用【杀】的目标后发动〖享乐〗，关羽受到〖武神①〗的影响能弃置一张红桃【麒麟弓】进行响应，因为此牌的牌名视为【杀】。
```
