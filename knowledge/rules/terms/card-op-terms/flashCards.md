# 亮出

若角色亮出的是：

1、牌堆顶的牌，即其将牌堆顶的牌置入处理区。

2、牌堆里的一张……牌，即若牌堆里：有……牌，执行此操作即系统从牌堆里的所有……牌中随机将其中一张移至处理区；没有……牌，执行此操作即没有事发生。

3、背面朝上放置且不是牌堆顶或牌堆里的牌，即其将这些牌翻转至正面朝上。

```
角色因判定而亮出牌堆顶的一张牌，即将牌堆顶的一张牌置入处理区。
```
