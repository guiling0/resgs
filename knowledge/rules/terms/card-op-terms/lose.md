# 失去<牌>/<手牌>/<装备区里的牌>

角色的牌移至除其手牌区和装备区外的区域，即其失去这些牌；角色的手牌移至目标区域，即其失去这些手牌；角色的装备区里的牌移至目标区域，即其失去装备区里的这些牌。

```
虞翻对装备【八卦阵】的邓艾发动〖直言〗，邓艾摸一张牌，经展示为【藤甲】，然后邓艾使用此【藤甲】，先将此【藤甲】对应的实体牌置入处理区，在此【藤甲】对应的实体牌置入处理区后❷发动〖屯田①〗，然后将此【藤甲】对应的实体牌置入其装备区的同时将装备区里的【八卦阵】置入弃牌堆，在此【八卦阵】移至弃牌堆后❷能再发动一次〖屯田①〗。最后邓艾回复1点体力。
```
