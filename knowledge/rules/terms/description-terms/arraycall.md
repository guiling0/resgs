# 阵法召唤

A须满足下列五个条件，才能阵法召唤：

1、A有势力且不为野心家。

2、A有一张武将牌处于明置状态且此武将牌有阵法技。

3、除A外存在没有势力的角色。

4、与A势力相同的所有角色数小于玩家数的一半。

5、根据此阵法技的发动条件的不同，判断A能否阵法召唤的条件5也会不同：

（1）与围攻有关。

a、A的上家与A势力不同，且A的上家的上家没有势力。

b、A的下家与A势力不同，且A的下家的下家没有势力。

a和b满足其中一条，判断A能否阵法召唤的条件5即满足。

（2）与队列有关。

a、A按顺时针方向的路径至一名没有势力的角色，在路径上没有与A势力不同的角色。

b、A按逆时针方向的路径至一名没有势力的角色，在路径上没有与A势力不同的角色。

a和b满足其中一条，判断A能否阵法召唤的条件5即满足。

**围攻阵法召唤的处理**：若满足条件5-（1）-a且不满足b，则A的上家的上家若明置后势力与A相同，其选择是否明置一张或同时明置两张武将牌响应；若满足b且不满足a，则A的下家的下家同理；若a、b均满足，则A的下家的下家先选择，A的上家的上家后选择。

**队列阵法召唤的处理**：沿满足条件的路径依次检测无势力角色——满足a时从A开始按顺时针检测，满足b时按逆时针检测；第一名无势力角色若明置武将牌后势力与A相同，其选择是否明置一张或同时明置两张武将牌响应；若其明置了武将牌，继续沿同方向检测下一名无势力角色并重复此流程，直到无满足条件的角色。若a、b均满足，先按逆时针检测，后按顺时针检测，已在此次阵法召唤中明置过武将牌的角色不再参与检测。

注：成功发动此阵法召唤意味着A的下家或/和上家成为被围攻角色。

注：成功发动此阵法召唤意味着以此法明置武将牌的角色与A处于一个队列中。此阵法召唤的结算顺序可简单概括为依次执行的两个流程：①若满足条件b，则：从A开始，按逆时针顺序检测第一名无势力角色，若其明置武将牌后仍满足条件b，其可明置武将牌，若其明置了武将牌，重复此流程。②若满足条件a，则：从A开始，按顺时针顺序检测第一名无势力角色，若其明置武将牌后仍满足条件a，其可明置武将牌，若其明置了武将牌，重复此流程。
