# A令B

A令B执行某操作，即指令由A发出，动作由B执行。若B指代的是一名角色且不能执行此操作，则A不能令B执行此操作，但若此操作为弃置，则只要B有符合弃置要求的牌，A就能令B执行此操作。若B指代的是多名角色，则其中只要有一名角色能执行此操作，A就能令B执行此操作。

注：通俗地说，就是说了行为是弃置的三种情况：当B是角色群时，有一名角色能弃置，就能执行；当B是角色时，只要B这个角色能弃置就能执行；当B是角色时，只有当B不能弃置时，这个行为才是不能执行的。特别地，弃置以外的行为，除了之前提过的回复体力以外，必须完全吻合行为的需求量才能执行。
