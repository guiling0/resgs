# <一名角色>回复<X>点体力

若Y：为0，其不能执行此操作；不小于X，其正常执行此操作；大于0但小于X，其能执行此操作，但须改为回复Y点体力（Y为其已损失的体力值）。

```
若所有角色均未受伤，周瑜（神）发动〖琴音〗只能选择执行令所有角色各失去1点体力的效果。
```
