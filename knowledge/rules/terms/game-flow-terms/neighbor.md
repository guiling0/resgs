# 上/下家

一名角色左/右手边的角色即其上/下家。

◆一名角色不能成为自己的上家或下家。

```
全场只有A和B两名角色，则：A即是B的上家，也是B的下家；B即是A的上家，也是A的下家。若A于其回合内对B使用【调虎离山】，则A于此回合内没有上家和下家。
```
