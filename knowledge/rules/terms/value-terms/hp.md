# 体力

一个数值。角色的初始体力等于其体力值。

注意：角色的体力有可能小于0。

```
体力为1的庞统-甘夫人在判定阶段受到渠道为【闪电】的3点雷电伤害，进入濒死状态，进行濒死结算，轮到其进行响应时其发动〖涅槃〗，当其将体力回复至3点时，其至多能发动五次〖淑慎〗。
```
