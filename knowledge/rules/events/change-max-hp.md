# 体力上限改变事件

角色改变体力上限的流程（改变的点数为正即加体力上限，为负即减体力上限）：

首先确定改变的体力上限点数。

改变体力上限结算中有：体力上限改变开始时、体力上限改变前、体力上限改变后三个时机。

### 体力上限改变开始时

### 体力上限改变前

### 体力上限改变后

然后其一次性改变X点体力上限，即其更换一张勾玉数为Y的体力牌，露出Z个勾玉。（若为加体力上限：X为确定的加的体力上限点数，Y为其于改变前的体力上限与X之和，Z为其于改变前的体力牌上露出的勾玉数；若为减体力上限：X为确定的减的体力上限点数，且X小于其体力上限，Y为其于改变前的体力牌上的所有勾玉数与X之差，Z为其于改变前的体力牌上露出的勾玉数，若其于改变前未露出的勾玉数不大于X，露出所有勾玉并将体力改为Y，若大于X，露出Z个勾玉）

◆若为减体力上限且X不小于其体力上限，其一次性减X点体力上限，即其死亡。

然后若其体力上限为0，终止改变体力上限流程，其死亡。

```
马岱（旧将）对邓艾数次发动〖潜袭〗，导致邓艾的体力上限为1。此时邓艾发动〖凿险〗减1点体力上限，由于体力上限为0，直接死亡，不能被挽救。
```

```
马岱（旧将）在使用【杀】对距离为1且体力上限为1的庞统造成伤害时2发动〖潜袭〗，判定结果不为红桃，马岱防止此伤害，庞统减1点体力上限，由于体力上限为0，直接死亡（并非马岱杀死），不能被挽救（因此庞统不能发动〖涅槃〗）。
```

至此改变体力上限结算结束。

改变体力上限结算后有：改变体力上限结算结束后一个时机。

### 改变体力上限结算结束后


至此改变体力上限流程结束。

注：在需要的体力牌不够用的情况下，可以用身份牌遮住体力牌右侧的勾玉表示减相同数量的体力上限。另外，在露出一定数量的勾玉后，角色的体力也就与露出的勾玉数相同。值得注意的是，这段话中是用“露出勾玉”表达体力的变化。这种变化不是受到伤害，也不是失去体力，只是对体力值的一种调整。
