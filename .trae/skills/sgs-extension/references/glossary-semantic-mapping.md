# 标准描述 ↔ 详细描述 语义对照表

> **详细描述**（规则集描述）：遵循游戏规则集的精确表述，使用标准符号（〖〗【】{}▶▷→①②③◆❸）和严格术语。
> **标准描述**（通俗描述）：面向玩家的简化表述，省略内部游戏机制细节，更符合直觉理解。

## 转换工作流

```
标准描述 → 识别关键用语 → 查权威文档确认术语定义 → 按以下规则逐条翻译 → 详细描述
                │                    │
                ▼                    ▼
         本表"转换规则"       references/authority-terms.md
                             references/authority-definitions.md
                             references/authority-timing.md
```

> **重要**：转换时必须参照 [authority-terms.md](authority-terms.md) 确认游戏用语的精确 API 映射，参照 [authority-timing.md](authority-timing.md) 确认时机序号和语义，参照 [authority-definitions.md](authority-definitions.md) 确认技能六要素和元规则。

## 分类转换规则

### 一、时机与阶段

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| T1 | "……阶段"（非出牌阶段缺省） | 精确到子时机："……阶段开始时/结束时" | 闭月、观星、妄尊 |
| T2 | "出牌阶段" | **保持**，不展开为空闲时间点 | 青囊、制衡 |
| T3 | 隐式时机（"若你未于……"） | 显式写出触发时机 + 区分"未执行过X或于X内未……" | 克己 |
| T4 | "你的回合外" | "当你**于回合外**需要……时"——条件在时机描述内部 | 急救 |
| T5 | "限一次/限X次" | **保留**，不省略 | 青囊、离间 |
| T6 | "或"连接两个不同触发时机 | 拆为①②两个独立 Effect | 急援 |
| T7 | "并非因响应于{…}而需要……时❶" | 排除从句——防止嵌套使用/打出流程中重复触发。❶=非因响应的need timing | 激将 |
| T8 | ❸ vs ❶ | ❸=转化技need timing；❶=非因响应的need timing。**实现中❸→2** | 武圣、激将 |
| T9 | "交给……时"（操作作时机） | "因……交给而得到牌后❷"——操作≠时机，"交给"的触发时机是对方的"得到后❷" | 急援 |
| T10 | "判定牌生效" | "判定结果确定"——"生效"/"确定"是不同的子时机。"确定前/后"需加序号❶❷ | 鬼才、天妒 |

### 二、使用 / 打出 / 转化

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| U1 | "将X牌当Y使用/打出" | "当你需要使用/打出Y时❸，你可使用/打出对应的实体牌为X牌的Y" | 武圣、龙胆 |
| U2 | 纯"使用"（无"打出"） | "当你需要使用Y时❸，你可使用对应的实体牌为X牌的Y" | 国色、急救 |
| U3 | 转化来源约束 | "手牌"限区域、"黑色/红色"限花色、"方块"限花色——不同于武圣的"红色牌"不限区域 | 倾国、急救 |
| U4 | "令A视为对B使用【X】" | "A对B使用**无对应的实体牌**的【X】"——去掉"视为"，用"无对应的实体牌"表达虚拟 | 离间 |
| U5 | "对应的实体牌为X" vs "无对应的实体牌" | 转化技=有实体牌对应；凭空生成=无实体牌对应 | 武圣 vs 离间 |
| U6 | "当你使用【X】指定/使用时" | 牌中心视角："当【X】指定目标后/被使用时，若使用者为你" | 铁骑、集智 |
| U7 | "需X张【Y】才能抵消" | "将抵消此【杀】的方式改为依次使用X张【Y】" | 无双 |

### 三、目标与合法性

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| G1 | "不能成为【X】的目标" | "不是【X】的合法目标"——双重否定，状态类限定合法目标的标准句式 | 空城、谦逊 |
| G2 | "只能以你为目标" | "除你外的角色不是……的合法目标"——从"允许谁"翻转为"禁止谁" | 同疾 |
| G3 | "转移给" | **直接使用，不展开**。"转移给"是规则集定义术语 | 流离 |
| G4 | "选择一名……角色"（转移场景） | 补充"是此牌的合法目标且与此牌的目标列表中的所有目标均**无对应关系**的角色" | 流离 |
| G5 | "（距离关系限制规则对此次合法性检测不产生影响）" | 括号豁免——合法目标检测时忽略距离限制（外层"攻击范围内"已约束） | 流离 |
| G6 | "不能成为A和B的目标" | "不是A**或**B的合法目标"——否定语境下"和"→"或" | 谦逊 |
| G7 | "不能使用【闪】响应此【杀】" | "此【杀】**于对此目标进行的使用结算中**不是此目标对应的角色使用【闪】的合法目标"——三个关键：①"于…使用结算中"作用域 ②双重否定 ③"此目标对应的角色"指代 | 铁骑 |

### 四、伤害与回复

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| D1 | "受到红色【杀】造成的伤害时" | "受到伤害时❷，若渠道为红色【杀】"——颜色修饰的是渠道（牌），不是伤害 | 耀武 |
| D2 | "受到N点伤害"（技能造成） | "受到你造成的N点**普通**伤害"——标出来源 + 伤害类型（普通/火焰/雷电） | 刚烈、反间 |
| D3 | "令一名角色回复体力" | "选择一名**已受伤的**角色▶其回复1点体力"——回复操作隐式约束：目标必须已受伤 | 青囊 |
| D4 | "回复的体力+1" | "**回复值基数**+1"——修改的是回复基数（非终值）。参见 authority-terms.md 数值公式 | 救援 |
| D5 | "对你使用【桃】回复的体力" | "使用的【桃】**于对对应的角色为你的目标的使用结算中**的回复值基数"——作用域限定在"对X的使用结算中" | 救援 |

### 五、数值与公式

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| V1 | "少摸X张牌" / "多摸X张牌" | "令额定摸牌数-X/+X"——通俗"多摸/少摸"的统一机制是修改额定摸牌数 | 裸衣、英姿 |
| V2 | "手牌上限-N" | 附加"若其手牌上限大于0"——数值修改隐式受下限约束（手牌上限≥0） | 妄尊 |
| V3 | "X为全场角色数且最多为Y" | "X=min{角色数,Y}"——用 `min{}`/`max{}` 表达约束 | 观星 |
| V4 | "不大于N" | "小于N+1"——详细描述统一用"大于/小于" | 义从 |
| V5 | "你计算与其他角色的距离" / "其他角色计算与你的距离" | "你**至**其他角色的距离" / "其他角色**至**你的距离"——"至"表达方向性 | 义从、马术 |
| V6 | "无距离限制"（锦囊） | "无**距离关系**的限制"——锦囊使用限制的正式术语 | 奇才 |

### 六、句式与操作

| # | 标准描述 | 详细描述 | 实例 |
|---|---|---|---|
| S1 | "改为……" | 显式写出被替代的操作 + 新操作，用 ▶ 连接 | 突袭 |
| S2 | "然后"（即时效果） | `▶`——消耗→效果连接 | 青囊、苦肉 |
| S3 | "然后"（延时效果） | `▶（→）当……时……`——延时效果在后续独立时机触发 | 裸衣、洛神 |
| S4 | "观看牌堆顶的牌" | "将牌堆顶的牌扣置入处理区（对你可见）"——"观看"的实现是移入处理区+可见标记 | 观星、遗计 |
| S5 | "代替之" | 展开为"打出对应的实体牌▶系统将此牌作为……"——"代替"不保留 | 鬼才 |
| S6 | "任意张" | "至少一张"——规则集不允许"任意"=0 | 仁德、制衡 |
| S7 | "交给任意角色"（多张牌） | 展开为分配选项："1.将A给X、B给Y；2.将A和B给X"——"任意"=分配自由度 | 遗计 |
| S8 | "猜一种花色" | "选择一种花色"——"猜"是博弈用语，"选择"是操作描述 | 反间 |
| S9 | "展示之" + "若猜错" | "展示…获得此牌并**记录此牌的游戏牌ID**。若为此ID的牌不是…"——状态快照。牌获得后可能被洗混，判断需基于记录时的牌面信息 | 反间 |
| S10 | "重复此流程" | `◆此流程即"……"`——◆标注循环体的边界 | 洛神 |
| S11 | "主公" / "XX势力角色" | "身份为主公的角色" / "XX势力的角色" | 妄尊、激将 |
| S12 | "本回合" | "于此回合内" | 妄尊、裸衣 |
| S13 | "以此法" | "因执行此技能的消耗而…"——区分操作归属 | 仁德 |
| S14 | "或"（由他人选择） | "你令X选择：1.……；2.……"——明确选择权归属 | 耀武 |
| S15 | "其" | 指代消耗段选中的目标角色 | 青囊、结姻 |

## 实例对照

### 突袭
- **标准**：摸牌阶段，你可以改为获得至多两名其他角色的各一张手牌。
- **详细**：摸牌阶段开始时❷，你可令额定摸牌数改为0并选择至多两名有手牌的其他角色▶你获得这些角色的各一张手牌。
- **规则**：S1(改为→显式)，T1(阶段→子时机)，V1(额定摸牌数)

### 无双
- **标准**：锁定技，你使用的【杀】需两张【闪】才能抵消；与你进行【决斗】的角色每次需打出两张【杀】。
- **详细**：①锁定技，当【杀】指定目标后，若使用者为你，你将此目标对应的角色抵消此【杀】的方式改为依次使用两张【闪】。②锁定技，当【决斗】指定目标后，若使用者为你，你将此【决斗】的作用效果改为{由目标对应的角色开始，其与你以"其，其，你，其，其，你……"的顺序依次打出【杀】，直到其与你中的一名角色未打出【杀】。未打出【杀】的角色受到其与你中的另一名角色造成的1点普通伤害}。③锁定技，当你成为【决斗】的目标后，若此【决斗】的作用效果：未受到过〖无双②〗的影响，你将此【决斗】的作用效果改为{由目标对应的角色开始，其与你以"其，你，你，其，你，你……"的顺序依次打出【杀】，直到其与你中的一名角色未打出【杀】。未打出【杀】的角色受到其与你中的另一名角色造成的1点普通伤害}；受到过〖无双②〗的影响，你将此【决斗】的作用效果改为{由目标对应的角色开始，其与你以"其，其，你，你，其，其，你，你……"的顺序依次打出【杀】，直到其与你中的一名角色未打出【杀】。未打出【杀】的角色受到其与你中的另一名角色造成的1点普通伤害}。
- **规则**：U7(抵消方式改变)，U6(牌中心视角)，S1(改为)，D2(伤害类型)

### 武圣
- **标准**：你可以将一张红色牌当【杀】使用或打出。
- **详细**：当你需要使用/打出普【杀】时❸，你可使用/打出对应的实体牌为你的一张红色牌的普【杀】。
- **规则**：U1(转化技)，T8(❸→实现中改为2)

### 仁德
- **标准**：出牌阶段，你可以将任意张手牌交给其他角色，每阶段你以此法给出第二张牌时，你回复1点体力。
- **详细**：出牌阶段，你可将至少一张手牌交给一名角色▶若你于此阶段内因执行此技能的消耗而交给其他角色的手牌数大于1，且于此次发动此技能之前于此阶段内因执行此技能的消耗而交给其他角色的手牌数小于2，你回复1点体力。
- **规则**：S6(任意→至少)，S13(以此法)，S2(▶)，T2(出牌阶段保持)

### 国色
- **标准**：你可以将一张方块牌当【乐不思蜀】使用。
- **详细**：当你需要使用【乐不思蜀】时❸，你可使用对应的实体牌为你的一张方块牌的【乐不思蜀】。
- **规则**：U2(纯使用)，U3(来源约束)，T8(❸→2)

### 流离
- **标准**：当你成为【杀】的目标时，你可以弃置一张牌并将此【杀】转移给你攻击范围内的一名其他角色。
- **详细**：当你成为【杀】的目标时，你可弃置一张牌并选择你的攻击范围内的一名是此【杀】的合法目标且与此牌的目标列表中的所有目标均无对应关系的角色（距离关系限制规则对此次合法性检测不产生影响）▶此【杀】转移给该角色。
- **规则**：G3(转移给不展开)，G4(合法目标+无对应关系)，G5(豁免括号)

### 急救
- **标准**：你的回合外，你可以将一张红色牌当【桃】使用。
- **详细**：当你于回合外需要使用【桃】时❸，你可使用对应的实体牌为你的一张红色牌的【桃】。
- **规则**：T4(回合外→时机内部)，U2(纯使用)，T8(❸→2)

### 青囊
- **标准**：出牌阶段限一次，你可以弃置一张手牌，然后令一名角色回复1点体力。
- **详细**：出牌阶段限一次，你可弃置一张手牌并选择一名已受伤的角色▶其回复1点体力。
- **规则**：T5(限一次保留)，D3(已受伤约束)，S15(其)

### 离间
- **标准**：出牌阶段限一次，你可以弃置一张牌并选择两名其他男性角色，然后令其中一名男性角色视为对另一名男性角色使用一张【决斗】。
- **详细**：出牌阶段限一次，你可弃置一张牌并选择一名能使用无对应的实体牌的【决斗】的其他男性角色A和一名是A使用无对应的实体牌的【决斗】的合法目标的其他男性角色B▶A对B使用无对应的实体牌的【决斗】。
- **规则**：U4(视为→无对应实体牌)，U5(有/无实体牌区分)

### 耀武
- **标准**：锁定技，当你受到红色【杀】造成的伤害时[2]，伤害来源回复1点体力或摸一张牌。
- **详细**：锁定技，当你受到伤害时❷，若渠道为红色【杀】，你令来源选择：1.回复1点体力；2.摸一张牌。
- **规则**：D1(渠道属性修饰)，S14(或→选择列表)

### 同疾
- **标准**：锁定技，若你的手牌数大于体力值，攻击范围含有你的角色使用【杀】只能以你为目标。
- **详细**：锁定技，若你的手牌数大于你的体力值，除你外的角色不是攻击范围内有你的角色使用【杀】的合法目标。
- **规则**：G2(只能→双重否定)

### 铁骑
- **标准**：当你使用【杀】指定一名角色为目标后，你可以进行判定，若结果为红色，其不能使用【闪】响应此【杀】。
- **详细**：当【杀】指定目标后，若使用者为你，你可判定▶若结果为红色，此【杀】于对此目标进行的使用结算中不是此目标对应的角色使用【闪】的合法目标。
- **规则**：U6(牌中心视角)，G7(使用结算作用域+双重否定)

### 观星
- **标准**：准备阶段，你可以观看牌堆顶的X张牌（X为全场角色数且最多为5），然后将这些牌以任意顺序放置于牌堆顶或牌堆底。
- **详细**：准备阶段开始时，你可将牌堆顶的X张牌（X=min{角色数,5}）扣置入处理区（对你可见）▶你将其中任意数量的牌置于牌堆顶，将其余的牌置于牌堆底。
- **规则**：T1(阶段→子时机)，S4(观看→处理区)，V3(min{})

### 鬼才
- **标准**：当一名角色的判定牌生效前，你可以打出一张手牌代替之。
- **详细**：当判定结果确定前，你可打出对应的实体牌▶系统将此牌作为判定牌。
- **规则**：T10(判定时机精确化)，S5(代替→展开)

### 裸衣
- **标准**：摸牌阶段，你可以少摸一张牌，然后你本回合使用【杀】或【决斗】造成的伤害+1。
- **详细**：摸牌阶段，你可令额定摸牌数-1▶（→）当你于此回合内因执行【杀】或【决斗】的效果而对一名角色造成伤害时❶，若使用者为你，你令伤害值+1。
- **规则**：V1(少摸→额定摸牌数)，S3(▶（→）延时标记)

### 遗计
- **标准**：当你受到1点伤害后，你可以观看牌堆顶的两张牌，然后将这些牌交给任意角色。
- **详细**：当你受到1点伤害后，你可将牌堆顶的两张牌扣置入处理区（对你可见）▶你选择：1.将其中的一张交给一名其他角色，将另一张交给一名角色；2.将这两张牌交给一名角色。
- **规则**：S4(观看→处理区)，S7(任意→分配选项)

### 洛神
- **标准**：准备阶段，你可以进行判定，当黑色判定牌生效后，你获得之并可以重复此流程。
- **详细**：准备阶段开始时，你可判定▶（→）当判定结果确定后❶，若结果为黑色，你获得判定牌。若结果为黑色，你可重复此流程。 ◆此流程即"你判定。若结果为黑色，你可重复此流程"。
- **规则**：S3(▶（→）)，S10(◆循环体)，T10(判定时机)

### 反间
- **标准**：出牌阶段限一次，你可以令一名其他角色猜一种花色，然后获得你的一张手牌并展示之，若猜错花色，你对其造成1点伤害。
- **详细**：出牌阶段限一次，若你有手牌，你可令一名其他角色选择一种花色▶其展示你的一张手牌，获得此牌并记录此牌的游戏牌ID。若为此ID的牌不是其选择的花色，你对其造成1点普通伤害。
- **规则**：S8(猜→选择)，S9(ID快照)，D2(普通伤害)

### 克己
- **标准**：若你未于出牌阶段内使用或打出过【杀】，你可以跳过弃牌阶段。
- **详细**：弃牌阶段开始前，若你未执行过出牌阶段或于出牌阶段内未使用或打出过【杀】，你可跳过此阶段。
- **规则**：T3(隐式时机→显式)

### 救援
- **标准**：主公技，锁定技，其他吴势力角色对你使用【桃】回复的体力+1。
- **详细**：主公技，锁定技，其他吴势力角色使用的【桃】于对对应的角色为你的目标的使用结算中的回复值基数+1。
- **规则**：D4(回复值基数)，D5(使用结算作用域)，S11(势力修饰)

## 符号约定

| 符号 | 含义 | 实现映射 |
|---|---|---|
| `〖〗` | 技能名 | `Skill.name` |
| `【】` | 游戏牌名 | `GameCard.name` / `VirtualCard` |
| `▶` | 消耗→效果连接 | `cost()` → `effect()` |
| `▶（→）` | 即时消耗 + 延时效果（后续时机触发） | `cost()` + `addEffect(tempEffect)` |
| `▷` | 效果链（左执行才能右） | 两个连续 effect，前返回真才执行后 |
| `①②③` | 同一技能内多个独立效果 | 多个 `SkillBuilder.addEffect()` |
| `❸/❶/❷` | 时机序号（规则集） | 对应 `TimingName` 枚举；❸→实现中改为2 |
| `{}` | 复合效果块 | 多步骤的 `effect` 回调 |
| `◆` | 实现级细节 / 循环体定义 | 算法级描述 |
| `" "` | 标记名 | `MarkHost.setMark()` |
