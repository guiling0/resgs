### 6. DOM 与 Canvas 同步缩放

`#dom-overlays` 容器（1920×1080）通过 JS 计算 scale 与 LayaAir 画布同步：

```
dom-overlays (fixed, transform:scale(s), 与 canvas 等比)
├── #page-entry    ← Entry DOM UI
├── #toast-layer   ← Toast
└── #loading-overlay ← Loading
```
