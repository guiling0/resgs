## 客户端架构变更

- **旧**：LayaAir 3.4 → 已存档至 `old/client/`
- **新**：Vite + TypeScript + 纯 DOM/CSS（无框架）
  - `client/src/ui/` — Widget 建造器 + 场景 UI 模板
  - `client/src/pages/` — 场景交互逻辑
  - `client/src/components/` — 可复用组件（聊天、座位、房间项）
  - `npm run dev` 启动 → http://localhost:3000

## 关键决策

1. 客户端 DOM 方案：Widget 建造器替代 innerHTML 硬编码，类型安全可复用
2. 场景 UI 模板与交互逻辑分离（`ui/` vs `pages/`）
3. 全局自适应：1920×1080 设计分辨率，`scale(min(100vw/1920, 100vh/1080))` 等比缩放
4. 聊天面板：静态缓存跨场景保留、房间消息退出即删、content-visibility 懒渲染
5. 端口：客户端 3000（Vite），服务端 12699（Colyseus）
