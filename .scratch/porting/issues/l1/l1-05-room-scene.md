# L1-05: 客户端 RoomScene（等待房间）

**Type:** task
**Status:** pending
**Blocked by:** L1-02

## 问题

客户端 RoomScene — 座位显示、准备/取消、聊天、等待开始。

> 注意：这是**等待房间**场景（准备阶段），不是游戏场景。游戏场景（GameScene）在 L2+ 实现。

### 场景入口

LobbyScene 创建/加入房间成功 → `SceneManager.enter('room', { room })`

### UI 布局

```
┌─────────────────────────────────────────────┐
│  房间名：xxx    模式：标准    人数：3/8      │
│                                             │
│        座位 1          座位 2               │
│      (玩家A·已准备)   (玩家B·未准备)         │
│                                             │
│        座位 3          座位 4               │
│        (空位)          (空位)               │
│                                             │
│  ... 更多座位 ...                           │
│                                             │
│  ┌──────────────────────────────────────┐   │
│  │ 聊天区                               │   │
│  │ [系统] 玩家A 加入了房间               │   │
│  │ 玩家A：大家好                        │   │
│  │ 玩家B：准备啊                        │   │
│  └──────────────────────────────────────┘   │
│  [输入框________________] [发送]            │
│                                             │
│  [准备] [取消准备]   [返回大厅]  [开始游戏]   │
└─────────────────────────────────────────────┘
```

### 状态监听

```ts
room.onStateChange((state: RoomState) => {
    // 更新座位 UI
    // 更新准备状态
    // 更新聊天
});
```

### 消息处理

```
"chat"         → 显示聊天消息
"kicked"       → 提示"你被踢出了房间" → 返回 LobbyScene
"game_start"   → 提示"游戏开始" → 跳转 GameScene（L2 占位）
```

### 操作

- **准备/取消准备**：`room.send('ready')` / `room.send('unready')`
- **聊天**：`room.send('chat', { message })`
- **踢人**：仅房主可见，`room.send('kick', { seat })`
- **开始游戏**：仅房主、全员 ready 后可用，`room.send('start_game')`
- **返回大厅**：`room.leave()` → 回到 LobbyScene

### 座椅位置

客户端 `config.ts` 已有 `SEAT_POSITIONS` 常量（8 人桌坐标），直接使用。座位号 0 是玩家自己（底部中央），1-7 是其他玩家。

## 验收

- 进入房间 → 看到自己和其他玩家
- 准备/取消准备 → 状态实时更新
- 聊天 → 消息广播给所有人
- 房主踢人 → 被踢者收到通知并返回大厅
- 全员准备 → 房主点开始 → 跳转占位 GameScene
- 有人离开 → 座位释放，其他人状态更新
